# Pinpoint-Threads

Threads Commerce & Engagement Automation Pipeline.

해외/국내 쓰레드에서 검증된 고반응 소비재 콘텐츠를 수집·가공하여, 다계정 쓰레드에 최적화된 톤으로 자동 발행하고 쿠팡 파트너스·무신사 큐레이터 수익을 창출하는 AI 기반 파이프라인.

상세 아키텍처 및 규칙은 [CLAUDE.md](./CLAUDE.md) 참조.
