# 검증된 수익 플레이북

**출처:** 3분 스레드(이동영 마케터·디하클) 1~2기 수강생 다수의 실제 수익 인증(2026-07~09) 분석. 우리와 같은 방법(스레드 + 쿠팡파트너스)으로 3개월에 300~1,600만원, 1년 1,150만원 달성한 사람들이 공통으로 말하는 것.

## 핵심 반전 — "조회수 낮음"은 병목이 아니다

성공한 사람들도 **조회 200~300대가 일상**이다("조회수 200~300대 나오는 날도 많았고 수익 널뛰기"). 우리 쇼핑 중앙 187과 비슷한 수준. **차이는 조회수가 아니라 아래의 볼륨·꾸준함·재탕·소재.** 조회 낮다고 좌절 말 것.

## 5대 원칙 (실증)

1. **볼륨·꾸준함이 전부.** 하루 1~3개라도 **매일**, 흐름 끊지 말고. 초반 2~3개월은 계정·팔로워 빌드업 구간(수익 마이너스·널뛰기 정상). "하루 30분 안 쓴 날도 습관처럼 올리니 수익." 조급함이 최대 적.
2. **재탕·복붙이 시간 대비 최고 효율.** 터진 글을 **여러 계정·여러 날 복붙**해서 우려먹기. 한 수강생은 개인사로 시간 없어 "복붙·재탕의 무한 향연"만 했는데 8월 565만원(월 최고). → 매번 새로 만들지 말고 **위너를 확산**한다(propagation).
3. **소재(상품·주제) > 필력.** "반응 터지는 소재 찾는 게 일의 반 이상." 글솜씨보다 **누를 이유 있는 소재 선택**이 절반. → 사람이 URL 큐레이션([[project_human_curates_ai_reproduces]])하는 게 이 지점.
4. **첫 줄 후킹 = 생명줄.** 1초 만에 스크롤 넘어감. **질문/숫자/충격**으로 눈길부터. 첫 줄이 약하면 나머지는 안 읽힘.
5. **캐러셀(이미지+글) 포맷.** 이미지 몇 장에 텍스트만 얹는 포맷이 **영상 대비 라이트하고 댓글 폭발**(한 수강생 캐러셀로 댓글 500개·일수익 12만원). 영상 추출 삽질 없이 시도 가치 큼.

## 리스크

- **쿠파스·계정 밴 흔함.** 다들 "수익화 계정 3개 날림", "누적 100만 원 날 쿠파스 경고로 메인 2개 한번에 날아감." → **계정 여러 개로 리던던시**, 정책위반(셀럽·효능 단정 등 [[feedback_verify_brand_facts_in_copy]]) 조심.
- 인스타(캐러셀)는 스레드보다 계정 밴 위험 낮다는 의견.

## 우리 현황 대비 갭 (2026-09-28)

- 계정 5활성(hanseoa 워밍업) · 총 발행 102 · **최근 1.4/일(너무 적음)** · 쇼핑 중앙 187.
- **갭 = 볼륨·꾸준함 부족 + 재탕 미사용 + 캐러셀 미도입.** 카피 미세튜닝이 아니라 이 3개가 우선.

## 실행 지침 (이 프로젝트에 적용)

1. **발행량 대폭↑** — 계정마다 매일. 쇼핑은 전체 하루 1건 캡([[project_publish_pacing]] 유지)이라 **일상·캐러셀을 매일 여러 계정** 돌려 볼륨·도달 baseline 확보.
2. **재탕 시스템** — 터진 글(일상 max 1.9만·쇼핑 5485)을 다른 계정에 복붙 확산. 14일 동일상품 dedup은 지키되, 일상·훅은 재탕 OK.
3. **캐러셀 포맷 도입** — 이미지+텍스트 카드 지원. 영상 없이 라이트하게.
4. **첫 줄 후킹 강제** — 카피 생성 시 1초컷 훅(질문·숫자·충격) 최우선. (winning-style에 반영)
5. **2~3개월 꾸준함으로 평가** — 일일 수익/조회에 흔들리지 말 것.
