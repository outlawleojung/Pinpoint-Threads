# 강의 → 시스템 반영 추적표

강의에서 뽑은 규칙을 **"어디에 어떻게 반영했는가"** 체계적으로 추적한다.
목적: (1) 중복/누락 방지 (2) 무엇이 실제 코드로 적용됐고 무엇이 문서/대기인지 한눈에 (3) 마지막 통합 정리의 기준.

분류:
- **✅ 코드 반영** — 프롬프트/로직 파일에 실제로 들어감(발행 시 자동 적용)
- **📄 문서만** — 사람 운영 규칙(시스템 소관 아님) → docs에 보관
- **⏳ 결정 대기** — 사용자 판단 필요(충돌/정책)
- **🔜 예정** — 남은 강의 마이닝 후 통합

## ✅ 코드 반영됨 (rule → 위치)

### 카피라이터 — 쇼핑 (`src/modules/shared/copywriter/winning-style.ts`)
- 두괄식 + 마지막 참여유도 = 필수 2개 / 사족 2~3줄 금지 [1강·피드백1]
- 밸런스게임 A vs B(선택지 2개만) · 질문 게시글당 1개 [1강]
- 가독성(첫 줄 짧게 · 2줄 안 띄움 / 3줄+ 띄움 / 4줄+ 2+2) [1강]
- 정보성 = 공유·저장 유도 [1강]
- **검증된 후킹 문구 리스트**(VERIFIED_HOOK_LINES: "소심발언합니다"·"제발 ~하지마"·"나 진짜 궁금해서 묻는다"·"사고 쳤다"·대상 지목형 등) [피드백1·2강]
- 삐끼 철학(흥미까지만·의심 유발·30%만 쓰기) [2강]
- 명품은 브랜드 키워드 첫 줄 맨 앞 [2강]
- 정체 숨기되 **최소 키워드는 첫 줄에** / 방법·비결 밝히지 마라 [피드백2]
- 금지어 추가: "형광등 켜졌다"·"광명 찾았다"(Gemini 남발)·"가성비"·"혜자" [피드백2]
- (기존) 정체숨김·논쟁유발·반어법·이미지 서술금지·특정문구 남발금지

### 카피라이터 — 일상 (`src/modules/shared/copywriter/index.ts` generateDailyBody)
- 두괄식·밸런스게임·질문 1개·가독성·공감(실패)·이모지 무영향 [1강]
- 검증된 후킹 문구(축약) + 사족 금지 [피드백1]

### 발행 게이팅 (`src/modules/pipeline-a/reach-health.ts`)
- 수익화 신생 계정 팔로워 폴백 100 → **300** [1강·2강·피드백1]

### 재탕 엔진 (`src/modules/shared/performance-feedback/repost-planner.ts` + 텔레그램 "재탕"/`/repost`) [1강·2강·피드백1·2]
- 위너: 72h 조회 1천+ 또는 조회300+ & 비율(쇼핑 댓글조회/조회≥10% · 일상·스하리 좋아요/조회≥8%)
- 텀: 쇼핑 3일 · 일상 7일 · 스하리 1일 (계보 마지막 발행 기준) · 원문 그대로 복제 → 기존 승인·페이싱 통과
- 쇼핑은 CLAUDE.md 14일 동일상품 룰 → 14일 내면 다른 적격 계정
- `Post.repostOfId` 계보 컬럼(마이그 20260929130000). 첫 실측: 후보 10개(최고 조회 19,944 미재탕)

### 버티컬 (`bot.ts` pickLeastUsedAccount · `propagation-planner.ts`) [1강·피드백1·2강]
- 성별 애매 상품 → 전 계정 허용(기존: 남성 계정 제외). 명시적 성별 상품만 톤 일치.

### 지인 추천 프레임(MSG) (`winning-style.ts`) [2강·피드백1·2]
- 허용. 단 원본 작성자 사연 복제·전문직 사칭·효능 창작은 금지 유지.

> ⚠️ 위 반영은 4개 강의 기준. **12개 완료 후 전체 기준으로 재검증**(뒤집히면 수정). 그 전까지 카피 프롬프트 추가 수정 동결.

### 🆕 통합 1차 (2026-09-30 · 강의 11개 기준 · 전략 문서 course-strategy.md)
- **재탕 엔진 보강** (`repost-planner.ts`): ①쇼핑 댓글조회 1천+ = 위너 [피드백3] ②저조 재탕(원본 대비 30% 미만)마다 텀 ×2(최대 ×8) 무제한 재도전 [4강] ③다른 계정 이관 시 **페르소나-화자 검사**(남편/시댁=여성 화자, 와이프/여친=남성 화자 ↔ 계정 성별) [4강] ④이관 대상도 **쇼핑 적격(도달 게이트)** 통과 필수 — 버그 수정(팔로워 25 계정에 쇼핑 재탕 배정되던 문제). 실데이터 재검증 완료.
- **300 미만 링크 금지 (사용자 결정 2026-09-30)**: `reach-health.ts` LINK_MIN_FOLLOWERS=300 하드 바닥 → 신규 쇼핑·확산·재탕 전부 적용. 발행기 안전망(SHOPPING & <300 → 고정댓글 생략·kind DAILY), 승인 카드 표시, 재탕 원 계정 <300이면 "링크 없이 일상글로". 실측: 링크 가능 = pikkseetem(324)만(sookck 372는 도달 억제).
- 남은 로드맵: 카피 프롬프트 통합 정리 → 쿠팡 검색결과 링크 폴백 → 페이싱 재설계 → 소재 엔진.

## ⏳ 결정 대기 (사용자 판단 필요)
1. **주변인 스토리텔링(MSG)** — 강의 핵심 기법("승무원/청담샵 언니가 추천", 지어낸 지인). 사용자 기존 규칙 "원작자 정황·관계 지어내기 금지"와 정면 충돌 → 코드 미반영.
2. **버티컬 = 계정별 성별·컨셉 통일 불필요** — 강의 반복. 우리 쇼핑 audienceGender 게이팅과 충돌 → 유지 중.
3. (참고) **재탕 자동화**(쿠팡3일/일상7일 + 위너 원문복붙) — propagation 로직 손봐야 → 별도 설계.
4. (참고) **수익화 물량**(강사 하루 10~15개 vs 현재 쇼핑 1건) — 사용자가 의도적으로 줄인 상태.

## 🔜 예정 (남은 강의 마이닝 후)

- **최종: 테마별 마스터 플레이북**(강의별 X → 계정운영/카피공식/승자표현 라이브러리/소싱/수익화/알고리즘으로 통합·중복제거).
- **승자표현 라이브러리** → 카피 few-shot에 반영 검토(현재는 문서에 인용 수집 중).
