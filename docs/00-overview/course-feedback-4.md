# 마스터반 피드백 4강 — 릴스 확장 + 스레드 전략

> 분량 대부분은 **인스타 릴스 과제 피드백**. 스레드에 직접 해당하는 것 위주로 정리. 코드 반영은 12개 완료 후 통합 때.

## ★★ 스레드 전략·운영
- **스레드 = 폭발·휘발, 인스타 = 느리지만 지속**: 스레드는 이틀만 안 올려도 수익이 끊길 수 있음(휘발성). 인스타는 한번 타면 1~2주. → "스레드로 폭발 수익 + 릴스로 꾸준 수익" 구조 권장. **스레드 카피 역량 자체가 자산**(스레드 글 그대로 릴스로 옮긴 게 공들인 릴스보다 잘 나옴).
- **운영 핵심 KPI = 볼륨과 작성 속도**: 강사가 수강생에게 묻는 것 = 하루 평균 수익화 글 몇 개, 글 하나 몇 분.
- **게시 빈도**: 팔로워 ~400이면 **수익화 글 2개 하루에 연달아도 OK**(시간 간격만). 일상글과 번갈아도 됨.
- **잘하는 사람들의 작성법**: 레퍼런스 **구조 분석** → 생성기/Gemini로 정보·초안 → 검증된 구조(깜짝 놀랐다 → 별거 아닌 줄 알았는데 → 장점)에 맞춰 **휴먼터치**. "날로 먹는 게 나쁜 게 아니다."
- **먹히는 멘트는 식상해도 그냥 계속 쓴다** — 한 번 잘 된 멘트를 다른 걸로 바꿔보지 마라. 표본 30개 영상 중 첫 멘트 ~90%가 "미쳤어요"였는데 계속 먹힘. "와~" 멘트는 저작권 없음.
- **카피 소싱 = 홈쇼핑 쇼호스트 CTA**: "이런 구성 이런 기회 처음", "오늘 이 시간 아니면 절대 못 받는다", "구하기 힘든데 오늘만 공개" — 그대로 스레드·릴스로 넘어옴.
- **해외 계정 전략**: 한국 스하리로 300명+ 모은 뒤 **일본어로 전환**(버티컬이라 이후 일본어 글은 일본인에게 노출). 프로필 "일본 살다 온 한국인/유학" 설정. 강사 수익화 계정 2개가 이 방식. 일본은 스하리 문화 없어 초반 느림. ⛔ 일본 자극 소재(야구·WBC) 악플 사례.
- 스레드도 중복 콘텐츠를 잡음(100% 안전 없음). 다만 아직 블루오션이라 신고 비율 낮음.
- **내 수익글 베끼는 악질 → 쿠팡파트너스에 저작권 신고**(스레드 신고는 약함). 일상·스하리는 가져가도 무방.
- 레퍼런스는 그 계정의 **목적(판매 vs 브랜딩·공구)**부터 파악 — 기업·잡지 계정은 수익화 레퍼런스로 애매.

## ★ 카피·구조 규칙
- ★ **희소성 템플릿(할 말 없는 상품)**: 앞뒤에 "구하기 힘들었다 / 한국에선 못 구한다 / 일본 가도 품절 / 여러분한테만 몰래 공유" → 발전형은 스토리 입히기. **쿠파스 링크 품절·사이즈 없음일 때 탈출구**도 됨. 구하기 쉬운 상품이어도 "조금은 뻔뻔해질 필요". ※ 우리 기존 룰 "지금 쿠팡에서 바로 살 수 있으니 '못 산다/아직 없다' 뉘앙스 금지"와 **충돌 → 최종 통합 때 정리**(희소·품절임박 FOMO는 기존에도 허용이라 경계 재정의 필요).
- ★ **수미상관 구조**: 결과물(After) → 불편함 공감 → 과정(힘들지 않을까 걱정 해소) → 결과물.
- ★ **"의심을 한 꺼풀씩 걷어내는" 흐름**(스레드에 그대로 사용 가능): 정보(전문성) → 비용 → "가짜 티 나지 않을까" 의심 해소 → 진짜 같다는 반응.
- **편견 깨기 첫 멘트**: "수육은 앞으로 항정살로 만들어 봐", "굳이 롤렉스 사지 말고…" 형식.
- **3자(남편) 시점 반전**: "와이프 아닌 줄 알았어요. 치마 샀다며 와보라는데 별거 있겠어 하고 갔다가 깜짝 놀랐어요" — "교과서적 레퍼런스".
- 레시피 콘텐츠 목적 = 링크 클릭. 재료 링크만 달면 안 누름 → "킥이 되는 재료/숨은 비법", "수육은 나는 여기서만 산다"를 댓글 유도 앞에 한 줄.
- 한 게시물 = 한 상품 집중(여러 개 나열하면 어떤 댓글 유도할지 애매).
- 상세페이지식 긴 설명·성분·인증 멘트는 릴스엔 되지만 **스레드엔 과함**.
- 소스(영상·사진)가 적으면 멘트도 줄여라 — 비주얼로 이미 보인 것, 소스 없는 것부터 뺀다. 장면 없는 소구점은 버려라(모든 포인트를 다 쓸 필요 없음).
- 모델명 풀네임 불필요("코치 신상 숄더백 등장"이면 충분). 스펙 단어("블랙폼") 빼고 "뉴발란스 미쳤다".
- 명품은 디테일(셔링·색감)보다 "실물 예쁨" 비주얼 중심.
- 첫 멘트 느낌표보다 여운 있는 "…"(스레드 감성).
- 해외 모델 소스는 "해외에서도 난리난 / 유럽에선 이미 유명한"으로 맞추면 사용 가능.
- "출시 8분 만에 매진 / 1분에 하나씩 팔리는" 섞어 쓰면 좋음 — ⛔ **사실 확인된 경우에만**.
- 벤치마킹 체크 3가지: ① 첫 장 이미지 ② 첫 멘트 ③ 템포(가독성·리듬).

## ★ 승자 표현
- "와 이 조합 진짜 미쳤다" / "사고 쳤다 / 사장님이 미쳤어요 / 1분에 하나씩 팔리는"(30년 전통 클래식 — 진부해도 쓴다, 세게)
- "제가 이거 사려고 두 달을 기다렸거든요"(홈쇼핑 계열)
- "네일샵 사장님들이 손님한테 절대 안 알려준다는 거 찾아왔어요… 네일샵 하는 친구가 쉬는 날엔 이것만 바른다고"(업계 내부자 비밀 + 전문가 지인)
- "빨대 꽂은 채로 닫힌다구요? / 손은 불편하고 얼음은 녹고… / 어 이게 되네"
- "와 샤넬 완전 샵 쳤다 / 가죽이 돌았어요 / 들자마자 전체 코디 급 올라가는 거 아시죠?"
- "빈티지한 색감에 미우미우 로고 조합은 진짜 반칙이죠 / … / 유행 안 타고 평생 들 가방"

## ⛔ 패자·주의
- "실물 색감 진짜 예뻐요"류 — 임팩트 약함. 일단 "미쳐야", "사고를 쳐야" 함.
- ⛔ **"내돈내산" 금지** — 뒷광고 논란 위험, 직접 샀다고 굳이 명시 X.
- ⛔ 공정위 문구 "받을 수 있다" X → "받습니다".
- 어려운 표현("쓰다가 감겨버린 텀블러", "무슨 짓을 해도 안 쏟아지는") → 직관적으로.

## 일반 (보강)
- ⛔ **원본 영상 통째로 사용 금지** — 제3자가 먼저 올려 악의적 중복신고 가능, 이의제기 받아들여져도 계정은 이미 날아감. 반드시 쪼개서 짜깁기. 일본인 제작 영상(일본인은 인스타 함)은 특히 많이 짜깁기. 샤오홍슈 영상은 틱톡에 올리지 마라.
- ⛔ 연예인 사진 사용 금지. 얼굴 나오면 블러.
- 게시글 삭제 알림 → 검토요청 → 완료 후 **4~5일** 쉬고 재개.
- 같은 링크 3번 반복은 링크 잘 보이게 하는 디자인 요소(1번도 무방) — 우리 REPLY_LINK_REPEAT=3과 일치.
- 새 계정엔 삭제된 이메일 재사용 X.

## 🔜 최종 통합 때 반영 후보
- 희소성 템플릿 vs 우리 "못 산다 뉘앙스 금지" 룰 경계 재정의.
- 볼륨: 팔로워 400급이면 수익화 2개/일 가능 → 현재 쇼핑 전체 하루 1건 캡 재검토.
- 카피 구조: 수미상관 / 의심 걷어내기 / 편견 깨기 / 3자 시점 반전 / 홈쇼핑 CTA.
- "먹히는 멘트는 바꾸지 말고 반복" ↔ 우리 "특정 문구 남발 금지" 룰 충돌 정리.
- "내돈내산" 금지어 추가.
- (장기) 해외(일본어) 계정 전략, 릴스 확장.
