# 전략 (북극성) — 강의 11개 통합

> 근거: 정규 1~4강, 마스터 1~3강, 피드백 1~4강 전사(총 ~60시간). 강의별 원문 정리는 course-index.md.
> 이 문서가 운영·코드 결정의 기준. 개별 강의 문서와 충돌하면 이 문서가 우선.

## 1. 한 줄 전략
**수익 = 소재 × 볼륨 × 재탕.** 카피 완성도가 아니라 **"궁금하게 만드는 짧은 글을, 안전한 계정에서, 꾸준히 많이 올리고, 터진 글을 원문 그대로 계속 재탕"**하는 시스템이 돈을 만든다.
- 강사 월 900만~1,300만의 90%+가 쿠팡. 신규 작업 없이 **재탕만으로 하루 10~20만원**(패시브).
- 꾸준함 > 양: 누적 5만원 넘긴 수강생들은 하루 1~10개. 하루 3개가 바닥선.

## 2. 우선순위 (모든 강의가 같은 순서로 말함)
1. **계정 안전** — 계정이 날아가면 전부 날아간다. 300명 전 수익화 금지·AI 레이블·점진 증량이 전부 이것.
2. **재탕 재고** — 터진 글(조회 1만+ / 댓글조회 1천+ / 비율 10%+)을 모아 원문 그대로 반복. "한 번 떴던 글은 다시 뜬다." 낮게 나와도 간격만 늘려 재도전.
3. **소재 속도** — 샤오홍슈 종합순 상위·이미지검색·구글 렌즈. 핫브랜드 × 시즌. 글 1개 5분, 재탕 1분.
4. **카피** — 두괄식 + 결말 숨기기 + 마무리. 이미 우리 수준 충분. 길게 쓰지 마라(~4줄).

## 3. 핵심 지표 (강의 확증 = 우리 KPI)
- 1차 조회수, 2차 **댓글조회/본문조회 ≥ 10%**(20%면 우수). 조회 클수록 비율↓ → 그땐 **댓글조회 절대수**(1천+면 좋은 글).
- 좋아요는 안 봄. 유머·동물·아기 = 좋아요↑ 수익↓ → 계정 활성화용.
- 조회 ≤100 = 계정 문제(3~4일 휴식), 200 = 회복 중, 0 = 글 문제.

## 4. 충돌 정리 (결정)
| 쟁점 | 결정 | 근거 |
|---|---|---|
| 마무리 질문 | **일상글 = 질문 OK / 수익화 글 = "링크가 답하는 질문" 금지**("써본 사람?", "어디 거?"는 셀프 Q&A). 의견·양자택일 질문은 OK. 기본은 손실회피·공감·반응으로 마무리 | 3강 vs 1강·피드백 |
| "광명 찾았다"류 | **금지 유지 + "미쳤다"·"반칙" 빈도 제한**(생성기 상투구) | 마스터1(최신, 강사가 생성기 4시간 튜닝) > 피드백3 |
| 먹힌 멘트 반복 vs 문구 남발 금지 | **재탕은 원문 그대로 반복 OK / 신규 생성은 변주**. 양립 | 피드백4·3강 |
| 희소성 vs "못 산다" 금지 | **"구하기 힘들었다·해외 품절·품절될 수 있으니" OK / "지금 못 산다·아직 없다·들어오면 산다" 금지**(판매 링크와 모순) | 피드백4·마스터1 |
| 재탕 기준 | **즉시 재탕**: 댓글조회 1천+ 또는 조회300+ & 비율 / **영구 재고(300개)**: 조회 1만+(현실 5천) — 두 층 | 3강·4강·피드백3 |
| 재탕 빈도 | 팔로워 규모 따라: 작을수록 텀 길게(쇼핑 3일), 낮게 나오면 텀 늘려 무제한 재도전 | 4강·피드백3 |
| 주변인 스토리 | 일반 지인 추천 한 줄 OK / 원작자 사연 복제·전문직 사칭 X | 2강·피드백 전반 |
| 성별 게이팅 | 애매 상품 전 계정 / 명시 성별만 톤 일치 + **페르소나-화자 일치 필수** | 1강·4강 |
| 자동 발행 봇 의심 | 공식 Threads API는 Meta 공인 경로(서드파티 예약 매크로와 다름) — 유지. 단 간격·지터·점진 증량으로 사람처럼 | 피드백3·4강 |

## 5. ⚠️ 사용자 결정 필요 (계정 안전 · 기존 방침과 충돌)
- **팔로워 300 미만 수익화.** 11개 강의 전부가 가장 강하게 금지("한 달 뒤 아이디 사라짐"). 현재 우리는 **도달 기반 게이트**라 kle0(118)·minyoung(183)도 쇼핑 발행 중. → 권고: 300 미만은 **링크 뺀 쇼핑 스타일 일상글**로 강등(강의 방식 — 반응 테스트 + 발행량 유지), 300 넘으면 링크.

## 6. 시스템 로드맵 (코드 반영 순서)
1. **재탕 엔진 보강** — ①댓글조회 1천+ 기준 추가 ②낮게 나온 재탕은 텀 늘려 재도전 ③**페르소나-화자 충돌 검사**(다른 계정 이관 시) ④재탕 시 링크 교체 옵션(실판매 상품 → 네이버/토스).
2. **카피 프롬프트 통합 정리** — 강의마다 덧붙인 규칙을 한 구조로: 첫 줄(두괄식·마법의 단어·결말 숨김) / 본문(30%·짧게 ~4줄·강한 줄 앞) / 마무리(일상=질문, 수익화=손실회피·공감) / 금지·빈도제한. 중복 제거.
3. **300 미만 강등 발행**(§5 결정 후).
4. **쿠팡 검색결과 링크 폴백** — 상품 매칭 실패 시 `브랜드 모델명` 검색결과 링크 + "품절될 수 있으니 모델명으로 확인" 문구.
5. **페이싱 재설계**(계정 성장 대비) — 팔로워 구간별 하루 수익화 캡(300명 1 / 500 2 / 1,000 3 — 강의보다 보수적), 주 단위 +1 증량. 현재 규모에선 변화 작음 → 후순위.
6. **소재 엔진** — 핫브랜드 × 시즌 캘린더(대목: 명절·아이폰 출시·블프), 샤오홍슈 종합순.

## 7. 사람 운영 (시스템 밖 — 사용자 매뉴얼)
- 계정: 7일에 1개 새로 만들어 숙성, 폰당 10개, 인스타·스레드 비번 분리, 교복·아기·AI실사 프로필 금지.
- 쿠파스: 매일 아침 가입 이메일 확인(72h 소명 안 하면 영구정지), 최종승인=매출 15만원+ & 스크린샷.
- 재고: 조회 1만+ 글을 "명예의 전당"에 보존(우리는 DB가 대신함).
- 확장(장기): 일본어/영어 계정(한국 스하리로 300 → 전환), 아마존, 쇼핑릴스, 광고 제안서.
