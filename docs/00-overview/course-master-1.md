# 마스터반 특강 1강

> 대부분 도구 실습(Vrew·Typecast·AI Studio·Edits·미리캔버스) — 쇼핑릴스·광고제안서 중심. 스레드 전략은 Q&A·마무리 로드맵([03:39]~).

## ★★ 운영 로드맵
- 단계별 루틴: 최소 하루 수익화 3개 → 10~15개 → **최종: 하루 수익화 10개 + 쇼핑릴스 1개**("이것만 해도 저 추월할 확률 높다").
- ★ 쿠파스 누적 5만원 넘긴 수강생들은 **하루 1~10개**(하루 1개도 있음) — **양보다 꾸준함**.
- 하루 10~15개가 상한, 단 **30개+ 가능한 환경**(추석·설날·한가한 날용 용량).
- ⛔ **재탕 1개 ~1분 — "재사용에 5분 걸리면 범죄".** 신규 5분. 처음 40분도 OK, 매 회차 단축(40→37…). 포기가 실패.
- 월 1회 판다랭크·홈쇼핑모아 고정 루틴. 잘 팔린 글은 네이버·토스 링크로(습관화).
- 수강생 수익의 **90%+가 쿠팡** — 한국 쿠팡만으로 "충분".
- 반복 작업의 귀찮은 단계를 전부 제거하라(마찰→피로→볼륨 붕괴). 파일 전송은 카톡 나와의 채팅(고화질/원본).
- ★ **해외 계정 확장**: 지금 별도 스레드 계정 만들어 일본어/영어 일상글 하루 1~2개(최대 3) → 아마존 어소시에이트 대비. 아마존 제휴글은 공정위 문구 불필요(보고). 시장 규모: 한국 < 일본 < 미국 < 동남아.

## 수익 채널
- 쇼핑릴스 퍼널: 릴스 → 캡션·영상에서 특정 키워드 댓글 유도 → 자동 DM(쿠파스 링크) → 프로필 인포크.
- 자동DM: 리틀리(무료·수동)로 시작 → 수익 나면 인포크(월 18,900, 쿠파스 링크 자동 생성). 비팔로워에게도 DM(돈 > 팔로워).
- ★ 명품·품절 가능 상품 DM: **"빠르게 품절될 수 있으니 모델명으로 상품 찾아주시면 됩니다"** — 재고 없는 링크의 소프트 면책 + 긴급성.
- ★ 쿠팡에 없는 상품 → `브랜드 모델명` 쿠팡 검색 → **검색결과 URL을 파트너스 링크로**(모바일은 "검색결과 공유", 간편링크는 모바일 에러 잦음).
- **광고 제안서**(PDF ~10p): 표지·강점(구매전환·멀티채널·기획·바이럴)·프로세스·채널소개·성과 캡처·단가표·프로모션. 템플릿 문구는 AI로 재작성(320명 동일 제안서 방지). 채널을 주제별(패션·리빙·푸드) + 주 연령·성별로 나눠 제시(광고주 편의 — 버티컬 설명 X). "**팔로우 수가 아닌 실제 성과**". 역제안: 2채널 동시 = 20~30% 할인.
- **스레드 3회 게시 단가**(팔로워): 소형=제품만 / 5~7천=5~10만 / 7천~1만=10~20만 / 1만+=20~30만 / 강한 브랜드 ~50만. 인스타 3~5천=제품 or 5만.
- 스레드 휘발성은 먼저 말하지 마라 — 광고주가 물으면 "6회 이상 or 여러 채널"로 업셀.
- ★ 광고 제안은 팔로워 200·300·2,000·3,000에서도 옴 — "팔로워는 중요하지 않다, 조회수만". 초반엔 제안서 밀지 말고 "제품만"도 경험으로 수락.

## 소싱
- 상품당 소스 **영상 2~3개 + 이미지 5~10개**(최소 5) — 재사용 탐지↓·컷 풍부.
- ★ AI 생성기가 브랜드를 놓침(트리옴페 패턴 보고도 "셀린느" 못 봄) → **브랜드 키워드 강제 삽입**(명품 글은 키워드 필수). 생성기엔 이미지 2~3장만.
- 명품은 쿠팡 썸네일 없음 → 샤오홍슈 가장 선명한 이미지 정사각 크롭.

## ★ 카피·구조 (쇼핑릴스 → 스레드 공통)
- ★ **스크립트 흐름**: 감탄사 → "아는 사람만 아는/유명" → 희소성(구매 제한 수치) → "다들 물어봄" → "명품 아닌데 그 느낌" → 누구에게 맞나 → "정보 구해왔다" → 특정 키워드 CTA.
- ★ **초보는 디테일 줄 삭제**(가죽결·형태·색·코디) — 희소성·하입·CTA에서 끝. 문장 하나당 영상 2~3컷 필요. **목표 스크립트 ~4줄.**
- 형용사 과다 AI 표현(곡선미·가죽결) 다듬기. AI 생성 이미지와 실소스 섞어도 시청자는 구분 못함.
- ★ **특정 키워드 CTA**("댓글에 가방/미니/니트") — 그냥 "댓글 남겨주세요"는 댓글 여론이 이상하게 형성될 수 있음.
- 캡션 댓글 CTA는 끝에서 **맨 앞으로** 이동.
- 해외 계정 일상글: 특정 집단 호명·추천 요청("시애틀 맛집 추천해줄래?", "플로리다 사는 사람 모여봐", Top10) — "사람 사는 거 다 똑같다".

## ★ 승자 표현
- 레퍼런스 릴스: "이 가방 미쳤어요 / SNS에서 이미 아는 사람만 안다는 가방인데 / 소문나서 주문이 몰려서 지금 1인 2개 구매 제한까지 걸렸대요 / 들고 나가면 사람들이 진짜 많이 물어봐요 '너 에르메스 켈리백 샀어?' / 근데 이거 에르메스 아니고 켈리백 느낌 미니 토트백이에요 / 명품백은 부담스럽고 켈리백 느낌 찾는 분들께 딱 / 어디서 샀냐고 계속 물어보길래 제가 정보 구해왔어요 / 궁금하시면 댓글에 미니 남겨주세요" (감탄·내부자 독점·수치 희소성·인용 사회적증거·명품 대체·키워드 CTA)
- "사고쳤어요" / "요즘 옷 잘 입는 사람들 보면 이 트랙탑 하나씩 입고 있어요"(충동구매 고백 + 유행 편승)
- "찾았어요 / 예쁜데 편한 신발 찾기 은근히 어렵잖아요 / 운동화처럼 편한데 디자인은 플랫"(공통 고통 → 해결)
- 강사 2분 작성 4줄: "와 셀린느 이 라인은 진짜 반칙이죠 / 실물 보고 기절할 뻔 했잖아요 / 실물 컬러감까지 완벽해서 어떤 코디든 뚝딱이네요 / 댓글에 가방 남겨주시면 정보 바로 보내드릴게요"

## ⛔ 패자
- ★ **생성기 상투구 "광명 찾았다"·"휘뚜루마뚜루"·"수직상승"** — 강사가 생성기를 4시간 튜닝해 10개 중 1개로 줄임. **새 남발어 "미쳤다"·"반칙"도 제한 필요.** (→ 피드백3의 "광명찾음 좋은 문구"보다 이쪽이 최신·정본: **식상 표현은 빈도 제한**으로 정리)
- 키워드 없는 "댓글 남겨주시면".

## 계정 안전
- ⛔ 소스 화면녹화 시 **첫 프레임 건너뛰고 중간부터**, 편집에서도 시작점 변경 — 재사용 탐지↓(보장 X).
- ⛔ 영상 "광고" 표기 **전 클립 적용**, 상단 끝에 딱 붙이지 마라(기기별 잘림 → 신고).
- ⛔ DM도 공정위 문구 맨 위. 자동답글 변주 **최소 5개(리틀리)/10개(인포크)** — 동일 반복 답글 = 매크로 판정 → 정지.
- ⛔ 인스타 릴스 **15개 전엔 "댓글에 OO" 문구 전부 삭제**(스레드 300명 규칙의 인스타판). 같은 스크립트·소스 릴스 동시 다량 업로드 위험. 릴스 재업로드는 1개월+ 후 안전.
- ⛔ 쿠파스 원링크를 단톡에 공유하면 파트너스 ID 노출.
- ⛔ 정치 콘텐츠(트럼프 좋다/나쁘다) = 즉시 정지. 연예인 콘텐츠 재녹화 X.
- 임시저장 대량 삭제는 계정에 영향 X.

## 알고리즘
- ★ **미신 반박: "올리고 바로 나가면 계정 죽음, 10~30분 앱에 머물러야"는 거짓**(인스타 속설). 게시자 본인 활동은 도달을 결정하지 않음. 100% 확신하는 사람은 "내부 개발자 아니면 사기꾼".
- ★ **노출은 쓰는 언어 + 좋아요·조회한 언어로 결정**(일본어→일본인, 호주에서 한국어→현지 한국인). **미래 행동만 반영** — 과거 한국어 글이 영어·일본어 전환을 막지 않음.
- 샤오홍슈 이미지 가져온 글이 바이럴 나는 패턴 확인.

## 🔜 통합 후보
- **생성기 상투구 빈도 제한**(광명·휘뚜루·수직상승 + 미쳤다·반칙) — 금지 목록 + 빈도 제한 방식으로 정리(피드백3 충돌 해소: 1강 최신 정본 채택).
- **특정 키워드 CTA**(2글자) — 우리는 고정댓글 링크라 본문 CTA 불필요하지만, 댓글 유도 방식 참고.
- **쿠팡 검색결과 링크 폴백** — 상품 매칭 실패 시 검색결과 URL로 딥링크(3강과 동일 → 구현 후보 확정).
- 초보 스크립트 ~4줄·디테일 삭제 → 카피 길이 규칙.
- 광고 제안서·단가표 → 사업 확장 문서(시스템 외).
