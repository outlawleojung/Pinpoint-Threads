# 마스터반 피드백 3강 — 성과분석 + 전략·운영

> ⚠️ 코드 반영은 12개 강의 완료 후 통합 시점에. 아래 "최종 통합 때 반영 후보"는 추적표로 이관.

## ★★★ 전략·운영 방향 (이번 강의 핵심)
- **재탕 = 변형 말고 그대로 복붙**(링크까지 그대로). 복붙한 게 오히려 더 잘 나온 사례. 글이 길수록 더더욱 복붙.
- **재탕 판단 KPI**: 댓글조회/조회 10%가 1차 기준. 단 **비율이 낮아도 댓글조회 절대수 1,000+ 면 바로 재사용**. 반대로 조회 600에 댓글조회 62(10%)처럼 **작아도 비율 좋으면 재사용**("파도 타면 대박"). "1만~1.5만 기준"은 너무 높다.
- **터진 글은 남에게 뺏기기 전에 반복**: 강사면 하루 1번씩 같은 멘트 3번+. 팔로워 200 수준이면 3일에 1번.
- **데칼코마니 운영**: 레퍼런스와 거의 같은 글은 "원본 ↔ 멘트 바꾼 버전"을 번갈아 매일.
- **조회 큰 글은 클릭률 낮아도 가치**: 13만 × 1% = 1,300 클릭. 79만 조회에 댓글조회 5%도 "잘 나온 것".
- **재활용 시스템**: 노션에 원문+쿠파스 링크 저장, 갤러리·노션을 Day1·Day2… 폴더로 그룹당 15~20개(분류 기준 정하지 말 것). **복붙용 백업 계정**(300명 채운 뒤 하루 1개). 계정 날아가도 원고·소재 보존.
- **재활용 목록은 시즌 바뀔 때(~3개월) 업데이트.**
- **시즌 재활용**: 비시즌에 부진한 과거 위너는 저장했다 수요 시즌에(발각질 11월말~1월말, 유니클로 후드 10월~, 린넨 원피스·회오리 에어컨·피지관리 여름). 예외보다 **대세·트렌드**에 집중(마케터지 영업 아님).
- **핫 브랜드(데이터상 1위면 내 취향 무관하게 한다)**: 자라·유니클로·설화수·라로슈포제(최다)·무인양품·샤넬·러쉬·도브·셀린느·나이키·뉴발란스 (+르무통·루이비통·룰루레몬·디올·달바·세포랩·헤라·마데카·스탠리). **"계절 상품과 조합"**(자라·유니클로 × 레더/청자켓, 하객룩 4~5월).
- **실구매 전환 잘 되는 것 = 저가 가성비템**(존슨즈 베이비오일, 도브 비누·브러시), 부담 없는 먹거리(이자카야 안주).
- ★ **유머·아기·동물 콘텐츠는 조회 터져도 수익 거의 없음**(하루 20개 유머 → 통합 2천만~5천만 뷰인데 수익 미미). 같은 조회라도 수익글이 돈. 일상글은 섞되 수익 기대 X.
- **소싱: 샤오홍슈가 압도적** — "결국 남는 건 샤오홍슈 + 직찍". 이미지 캡처→샤오홍슈 이미지검색으로 영상 찾기. 검색은 중국어/영어.
- **터진 글 기준 변형 대량생산**: 위너 상품명으로 샤오홍슈에서 관련 콘텐츠 다수 찾아 여러 버전 생산. 잘하는 카테고리 있으면 돌아가지 마라.
- **직찍**: 다이소·올리브영·무인양품·모던하우스·코스트코. 10개 10분. 가기 전 스레드에서 그 매장 검색해 구도 벤치마킹. 가방 없이 두 손 자유롭게.
- 글쓰기 1건 ~5분 목표(촬영+작성 10분 내외). 20~30분 쓰지 마라.
- **레퍼런스는 조회 1만 이하인데 비율 높은 글**에서 찾는 게 이상적.
- 트렌드 습관: 피드 훑기 → 레퍼런스 → 데이터 분석 → 강의 복습 → 핫브랜드 분석(월 1회, 최소 분기).
- 계정 하나는 수익화 글 많이 보고 좋아요 가끔 → 알고리즘을 레퍼런스용으로 최적화.
- 평균 3주차쯤 수익화 성공. 월 900만~1,200만 원 수강생도 있음.
- ⚠️ **[우리 시스템 리스크]** "1건 업로드 40초 이내로 줄이지 마라. 10~20초 자동 업로드(API·Claude Code 연동)를 일부러 안 하는 이유는 스레드가 봇으로 의심하기 때문. ⛔ 스레드 공식 예약 기능·예약 프로그램 써서도 정지 사례(일상글 포함)." → 우리는 공식 Threads API로 발행 중. **최종 통합 때 리스크 평가 필요**(발행 간격·지터·계정당 빈도로 완화 중인지 점검).

## ★ 카피·구조 규칙
- **구조 공식: 첫 멘트 = 훅 / 중간 = 상품 장점 / 마지막 = 불안함(손실회피) 또는 공감.**
- ★ **손실회피 > 이득**: "이거 없으면 고생한다 / 가방에 없으면 불안하다"가 "있으니 좋다"보다 압도적.
- 분량 무관(한 줄 OK). "친구한테 말하듯" — 평소 말투대로(내 옷을 입어라).
- **가장 강한 줄을 맨 앞으로** — 순서만 바꿔도 퀄리티 급변.
- ★ **정확한 가격 명시 X**("한 장 만원") → "3분의 1 가격" 같은 상대 표현.
- 남의 권위 빌리기: ①유명인 ②후기 ③주변 전문가(청소 이모님·30년 사장님·피부과 동생·치과 원장·일본인 친구·승무원).
- 카더라·통념 인용을 첫 멘트에("~래", "LG는 마케팅 못하는 걸로 유명").
- 상품 핵심(책 표지·가방)을 일부러 작게/안 보이게 → 궁금증으로 클릭. 단 정보를 다 줘도 10%+ 나온 역발상도 있음 — 핵심은 궁금증·공감.
- 사족 마지막 멘트는 본문에서 빼서 댓글로. 사진에 보이는 정보(스타벅스 등)는 본문에 반복 X.
- "이건 별로" 비교 글이어도 **링크는 본문에서 언급한 그 상품**에(대체품 X — "진짜 맛없나?" 궁금해서 클릭).
- 물음표 등 문장부호 디테일. 처음 보는 사람이 바로 이해되게. 모르는 상품명으로 시작 X.
- 레시피형이 트렌드(화장품도 토너→앰플→마무리 단계별). 넘버링·줄띄우기, 레시피 재료 중 쿠팡 상품에만 링크.
- 명품 이슈 → 반대편 가성비템 반전.
- 기억할 템플릿: "괜히 ○○이 아니네", "○○이 입은 거 드디어 찾았다", "아직도 ○○ 하나요?", "○○ 샀더니 매출 올랐다", "이거 나만 빼고 몰래 썼던 거야?", "○○ 미쳤나봐", "광명찾음"·"휘뚜루마뚜루"(※강사: 우리에겐 식상해도 **매우 좋은 마케팅 문구** — 피드백2의 "광명 찾았다 금지"와 충돌 → 최종 통합 때 정리).

## ★★ 승자 표현·문구 (원문)
- "남편이 이거 사놓으라는데 무슨 용도지?" (한 줄, 댓글조회 21%)
- "애 다 컸다고 당근 하지 마" → "어 왜?" + "남편이 아주 알차게 쓴다" (13만)
- "송월수건 살 바엔 나 이거 산다" (강력)
- "무인양품 이런 거 왜 홍보 안함?" / "홍보 왜 안함?" (6만, 누적수익 1등 수강생)
- "맘카페에 올렸더니 댓글 난리남" (5.9만)
- "이거 만든 사람 천재 아니냐" (교과서 첫 멘트)
- "이거 없으면 고생한다 / 가방에 없으면 불안하다" (손실회피)
- "존슨즈 베이비 오일만 써도 좋아진다고 왜 이제 말해준 건데" (후회 감성, 실구매 높음)
- "자라에서 아주 작정을 했네 / 이거 메고 출근했더니 다들 명품백인 줄 알았대"
- "괜히 아마존 1위가 아니네" / "이거 나만 빼고 몰래 썼던 거야? 리쥬란 뺨치는 비밀템"
- "남편 입 똥냄새 때문에 입을 틀어막고 싶었는데" (세고 강렬한 첫 멘트)
- "발 뒤꿈치 보고 충격먹어서 바로 결제함" (강력 첫 멘트, 효자상품)
- "(연예인)이 입은 거 드디어 찾았다" (연예인 콘텐츠 최고 멘트)
- "촉이 온다. 사놓자. 품절이다. 맛있다." (라임·리듬감 마무리)
- "아직도 ○○○ 하나요?" (단골 긁기) / "초딩 엄마는 이거 사" (타겟 호명)
- "떡볶이 사업도 대박 월에 얼마 벌까?" (수익 궁금 어그로 + 인플루언서 사업 홍보 = 삭제요청 안 받음, 40만)
- "광고 아니지? 어 미안한데 광고야" (마무리)
- 개선 예: "청소 이모님이 극찬하길래" → "오랜만에 청소 이모님께 맡겼는데 너무 깨끗한 거야… 실례를 무릅쓰고 뭘로 하셨냐 여쭤봤더니 이거라고… 와 속이 다 후련하다"(스토리텔링)

## ★ 패자 표현
- "와 진짜 이게 어떻게 굳으지? 뭔가 이상함" — 말하듯이 아님·판매 느낌(1%).
- "AI 한입 한입 컷" — AI 티, 광고 문구도 빠짐.
- "루이비통 숄더백 느낌 쩔어" + "이벤트" — 옛날 말투.
- "은은한 핑크펄 장난 아냐" — 친구한테 이렇게 말하는 사람 없음.
- "만원이면 미친놈급 / 한 장 만원" — 정확한 가격 + 시즌 불일치.
- "미우미우 플랫 이거 맞아?" — 로고가 크게 보이는데 "이거 맞아?"는 언밸런스.
- "프로그래머 친구가 이거 안 쓰면 해킹된다고" — 억지 신빙성 설정.
- "인공색소 버리고 과일즙으로 갈아타" — 광고 느낌.
- "진짜 완전 신세계" 칭찬 반복 — 중복.
- 식욕 떨어뜨리는 연출 + 상품 연관성 낮음.

## 일반 운영 (보강)
- ⛔ 계정 연속 삭제 시 7일 쉬고 일상글부터. 날아가자마자 재생성 반복 → 디바이스ID·IP 옐로카드 누적 → **공기계 + 알뜰폰 번호**. 강사도 수익화 전용 폰 별도.
- 수익글 삭제 반복 → 인스타 계정상태 점검·검토요청 → 완료 후 7일 묵히고 일상글만. 게시글 삭제되면 3~4일 텀.
- 링크 댓글은 발행 직후 바로(늦게 달면 댓글조회 급감).
- ⛔ 공정위 문구: "받을 수 있습니다"(가능성) X → **"받습니다"로 명확히**. 쿠팡파트너스 공식 문구가 가장 안전. 광고 표시는 맨 위·맨 앞.
- ⛔ **건강기능식품·영양제 금지(치약·칫솔 등 입에 닿는 것도 해당)**. 19금 불가. 혐오 소재(동물 학대 연상) → 파트너스 경고 사례.
- ⛔ AI 영상에 AI 라벨 없으면 신고 즉시 처리. 프로필에 본인 얼굴 X(추적 리스크).
- ★ 부정·조롱 댓글은 삭제·차단 말고 그대로 — 조회·클릭 유발. 작성자가 직접 대응 댓글 다는 디테일이 판매로(100개 판매 사례). 단 숟가락 얹는 홍보 댓글은 차단.
- 쿠파스 수익 1~2일 뒤 반영. 조회·댓글조회 큰데 수익 0이면 정식 파트너스 링크인지 점검.
- 오래 방치한 계정 조회 0 → 과거 잘된 글 복사/조금 변형해 꾸준히 → "혈이 뚫린다".
- 시즌 감각: 봄=다이어트·선크림, 여름=샌들·슬리퍼(백팩은 여름에 안 팔림), 바지·청바지 사계절, 제모 스테디.

## 🔜 최종 통합 때 반영 후보 (추적표 이관)
- 재탕 위너 기준에 **"댓글조회 절대수 ≥ 1,000"** 추가 (repost-planner).
- 재탕 텀을 **팔로워 규모별**로(강사급 매일 · 팔로워 200급 3일).
- 카피 구조 공식(훅/장점/손실회피 마무리) · 손실회피 · 가격 상대표현 · 강한 줄 맨 앞.
- "광명 찾았다" 금지(피드백2) vs "광명찾음 좋은 문구"(피드백3) 충돌 정리.
- API 자동 발행의 봇 의심 리스크 평가.
- 소재 엔진 방향: 샤오홍슈 중심 + 위너 상품명으로 변형 대량생산 + 핫브랜드×시즌 조합.
