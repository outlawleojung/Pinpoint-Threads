# 정규강의 2강 — 카피·소싱·수익화 심화

## ★★ 카피 철학 (핵심)
- **우리 역할 = "삐끼"**: 마케팅 퍼널(발견→흥미→의심→해소→욕망→구매)에서 **발견+흥미까지만** 만든다. 클릭 유도 X. **"의심"이 생길수록 좋다**(→링크 클릭). 상품을 다 설명·설득하려 하지 마라.
- ⛔ **후기처럼 써라, 홍보하듯 쓰지 마라**(전 강의 관통). 급해 보이면 실패.
- ★ **쓰고 싶은 내용의 30%만 써라**(블로그 반대). 많이 쓸수록 참여 여지가 사라짐 — 독자가 보완할 여백을 남겨라("대충 올리고 딴 데 간 느낌").
- ⛔ **은연중 "고맙다/좋다"(봐줬으면 하는 마음) 티 나는 문구 제거.** 정보 비대칭(덜 주기).
- **3대 후킹**: ① 질문 던지기 ② 정보성 나열 ③ 후기처럼(+공감대). 필요한 건 딱 3가지 중 1~2개: 궁금하게/호기심/공감.
- ⛔ **메인 키워드 게시글당 1개(많아야 2개). 첫 줄이 특히 중요.**
- ⛔ **속성 나열 금지**: "드디어 구한 아디다스 가젤 민트그린 조합"(색·소재·브랜드·코디·계절 5개) = 실패. 하나만.
- ★ **명품은 브랜드 키워드를 본문 맨 앞에**("구찌백"/"코치"). 명품=가격·신상 궁금→클릭.
- ★ **주변인 스토리텔링(MSG)**: 내가 아니라 주변인 이용 — "승무원 언니/청담샵 언니/샵하는 친구/형부". (승무원=비주얼·자기관리 검증 키워드). ⛔ 의사·변호사 사칭은 위험 → 물리치료사 등으로.
- ★ **나열식의 목적 = 저장/링크복사 유도** → 스레드가 강력 바이럴 신호로 인식 → 확산("마법의 단어"). "○○ 필수템 2개, 1..2.."
- **한 문장만 써도 된다**(마케터 관점). 광고표기 붙으면 70~80%는 클릭 안 함 — 그래도 흥미 끌면 클릭할 사람은 함(전환율 ~12% 관점, 88%는 원래 놓친 고객).

## ★★ 승자 표현·문구 (강사가 좋다고 한 실제 카피 — 그대로/변형 활용)
- "소심발언합니다" — 안 볼 수 없게 만드는 인트로.
- "새벽부터 편의점 돈다며? 와 여기 성지였네?" (질문+궁금)
- "이거 아직 안 써본 사람 있나요?" / "너네 이거 이미 알고 있었지?" (FOMO·긁기)
- "너네가 봤을 때 이거 자연스러워 보여? 솔직히 말해줘" (댓글 유도, 링크는 댓글)
- "와 이거 진짜 찐이더라. 나도 여러 번 사서 해봤는데 너무 좋더라" (★"남이 좋다더라"보다 "내가 해봤더니"가 훨씬 강함)
- "올리브영 가면 이것부터 집어" / "30초 돌리니까 이거 내 최애다"
- "팀장이 휴가 갔다 이거 사줬던데 무슨 의미야" (댓글 유발)
- "엄마가 루이비통 샀냐고 물어본, 근데 알고 보니 코치야" / "청담샵 언니가 추천했는데 안 쓸 수가 있나" / "코치가 이렇게 예뻤어?" / "코치 진짜 너무하다"
- "이거 보면 나만 빡치나?" (무엇 때문인지 보게)
- "머리 묶었을 뿐인데 갑자기 기술 들어간 머리 돼버림" / "로고 하나 바뀌었을 뿐인데"(로고 뭔데? 궁금)
- ★ 브랜드 "**사고 쳤다**" 매직 문장: "나이키/코치/아식스/아디다스/롱샴 사고 쳤다".
- 할인: "야 이거 너무 싼데? 이거 정품 아닌 거 아냐?" / "아이폰을 58만원에 판대요"(진짜인가 궁금→클릭, 안 사도 뭐 하나만 사도 수익)
- 연예인템: "카리나가 입었던 만원짜리 티 이거 맞아?" / "카리나가 입었는데 어깨가 살짝 좁게 나왔어"(★어깨 논쟁이 댓글 폭발 — 논쟁=엔진)
- 신상: "너구리 중에 앵그리 너구리 있었던 거 암?"

## ★★ 미디어 규칙 (중요)
- ⛔ **미디어 2개 이상 필수**(영상1+이미지1 또는 이미지2). 세로영상 1개만 = 화면 길게 차지→글·댓글 안 보고 스크롤→조회수·알고리즘 하락. 2개면 작고 깔끔.
- ★ **영상을 먼저**(역동적·시선강탈). 첫 화면은 움직이는 것.
- ⛔ **실사용 느낌 필요. 자막·비포애프터 = "업자 느낌" → 금지.**
- 영상 시작점은 역동적/후킹 부분부터(사람은 1~3초에 클릭 결정). 자막 지우려 편집하지 마라(시간 아까움) — 애매하면 버리고 다른 상품.
- 미디어 개수는 소재 관심도 따라 결과 다름(정답 아님, 이미지만도 잘될 건 잘됨).

## 상품 소싱·선정
- 소싱 5방법: ①태무 ②샤오홍슈 ③공홈 누끼컷 ④AI 생성기 ⑤쿠팡 (+최후 직접촬영).
- ⛔ **동일 상품 불필요 — 비슷하면 됨**(24h 내 아무거나 사도 수익). 신박/인기 찾지 마라 — **영상 있는 아무거나**.
- ⛔ **한국인 촬영** 후기 사진·영상은 신고 위험 → 중국인/외국인(일본인) 것 쓰기.
- 공홈 **누끼컷(흰 배경)** = 저작권 없음. 모델컷은 초상권 → AI가 효율적. 쿠팡 상세 이미지/영상은 파트너스 저작권 문제 거의 없음.
- 샤오홍슈: 명품 소싱(프라다/코치/디올/셀린느/샤넬/구찌). **영어·중국어로 검색**(한국어면 한국인 글). HDR ON·하단 버튼 OFF 후 화면녹화.
- ★ 꿀팁: 일본 인플루언서만 팔로우한 계정 → 피드가 일본 콘텐츠만 → 소싱 편함.
- 잘 터지는 소재: 숨겨진 템·신상템·연예인 착용템(카리나/정국). 정치 제외.

## 쿠팡 파트너스 수익화
- ⛔ **라스트 클릭**: 링크 클릭 후 24h 내 아무 상품 구매해도 수수료. 마지막 클릭한 사람에게 귀속.
- ⛔ 공정성/광고 표기 = **링크 다는 댓글 맨 앞**에 "광고". 3방법 중 하나만 지켜도 되나 강사는 셋 다(변수 차단). 링크가 광고문구보다 먼저 = 즉시 신고감. 본문엔 광고문구 안 써도 됨(댓글에만).
- ⛔ 미준수 = 수익 몰수 + 계정 삭제. 파트너스 **경고 3회=영구정지**. 신고 포상금 5만원 제도 有(조심).
- ⛔ 쿠팡 링크 댓글 **미리보기(프리뷰) X 하지 마라**(오류남).
- ⛔ 신고 시 **72h 내 회신 필수**. 조치: 문제글+동일재사용글 전부 삭제 + 직접 찍은 사진 새 글 3개 + 양식대로 메일. 스레드는 15분 후 수정 불가 → 결국 삭제.
- 고가 가전이 클릭률 좋은 것 아님 — 아무거나. 같은 성 가족도 링크로 다른 계정·다른 와이파이 구매해야 인정(본인 계정 구매는 수익 X).

## 계정 안전·발행 (2강 추가분)
- ⛔ 타 기기 로그인 알림 "본인 확인" 안 하면 **7일 뒤 정지**. 로그인/로그아웃 자주 X.
- ⛔ 게시글 "검토 중"이면 그 계정 건들지 마라. 검토 후에도 3일 휴식(가중처벌 회피). 검토 3~7일(최대 한 달).
- ⛔ **AI 이미지 = AI 레이블 필수**(미부착 시 3일 조회수 0·계정 죽음, 3계정 실측).
- ⛔ 얼굴 인증 셀카 전 계정 필수(안 하면 오히려 문제).
- 발행: 하루 10개 목표(개당 3~5분). 수익화글 연속 금지(사이 일상글). 300명 전 수익화 금지.
- 재탕: 쇼핑 3일 텀, 일상 7일 텀(계정 간 조회 잠식 방지). 팔로워 2000~3000 계정은 텀 없이 10개도 OK(텀은 계정 보호용).

## 알고리즘 (재확인)
- **알고리즘=파도**. 편법 없음(릴스 5분 안 끄기 등 카더라 전부 무관).
- **버티컬** — 게시글마다 개별. 일상글로 욕먹어도 수익화글은 관심층에 별개 노출.
- 저장·링크복사 = 강력 바이럴 신호. 논쟁·문화차이 유발 댓글도 노출↑(부정 댓글도 신호).
