# 마스터반 특강 3강

> 대부분 실습(인스타 캐러셀·페이오니아·아마존 가입·인스타툰). 스레드 전략은 마무리 루틴·Q&A([03:49]~[04:46])에 집중.

## ★★ 운영 루틴·목표
- 강사 수익 비중 **스레드 80~90%**, 그다음 릴스·인스타 캐러셀(성장 중). 스레드가 메인 엔진.
- ★ 신규 작업 거의 없이(강의로 바쁨) **재사용 콘텐츠만으로 하루 10~20만원**(안 좋은 날 5만원 이하, 평균 ~10만원). **재사용 재고 = 패시브 인컴.**
- ⛔ **수익화 글 1개 = 소싱 포함 5분 이하**가 최종 목표(10~30분은 실패). 쓰기가 시간 갈수록 어려워지면 안 됨 — 샤오홍슈가 취향 학습하니 그대로 가져오기.
- ★ **재사용 수익글 확보 목표 30개**(현 단계 5~10개가 정상). ※ 3·4강의 "300개"는 장기 목표, 여기선 중간 목표.
- 계정 계속 추가, 동시 발행 가능 수 30+로.
- ⛔ **아무리 바빠도 최소: 수익화 글 하루 3개 + 쇼핑릴스 3일에 1개.**
- ★ **최종 루틴: 수익화 글 하루 10+, 쇼핑릴스 하루 1+, 인스타 캐러셀 3일에 1개.** 영상 부담되면 최소 스레드 10개 — "그래야 돈 벌어요".
- ★ **300 미만 계정도 수익화 스타일 글을 링크만 빼고 계속** — 발행량 멈추지 마라.
- 트렌드(판다랭크·홈쇼핑모아) 1~2주에 1번, 계절 바뀔 때 반드시.
- 도구: Gemini **빠른 모델**(thinking/pro는 느림 — "우리는 시간이 돈인 사람"). 글·이미지 생성은 GPT≈Gemini.

## 수익 채널 확장
- ★ **인스타 게시물(캐러셀)이 최근 강하게 밀어줌**(릴스만이 아님).
- 같은 캐러셀을 **마지막 "댓글 유도" 카드만 빼고** 스레드에도 올릴 수 있음.
- 인스타 캡션엔 "댓글에 OO 남겨주면 정보 보내드릴게요"(댓글→DM 퍼널) 필수.
- **아마존 어소시에이트(미국·일본) via 페이오니아** — 스레드 플레이북을 해외로. 일본은 라쿠텐 쪽, 동남아 쇼피. ⛔ 180일 내 판매 3건 미만이면 탈락 → 각오하고 시작. 원링크 Select All.
- ★ **해외 계정**: 300명 먼저. 한국 스하리로 300 모은 뒤 일본/미국 활동으로 전환(강사 지지).
- 국내 기타 제휴: 지그재그·무신사·올리브영(해당 플랫폼 구매만 인정이 단점).

## 카피·구조
- ★ **캐러셀 구조**: 1장 = 제목·썸네일(훅 2줄 이하, 상품 선명) / 중간 = 내용(친구 말투, 1장에 없는 칭찬 디테일: 핏·수량제한·일본인이 쟁인다·직접 입어봤더니) / 마지막 = "댓글에 OO 남겨주세요"(키워드 **2글자 이하**). **이미지 3장이면 충분.**
- ★ **"직관적"이어야 하는 이유**: SNS는 쉬는 시간·자기 전·화장실에서 **뇌 30%로** 스크롤 — 주제가 바로 내 것이 아니면 즉시 이탈.
- ⛔ **나열식(1·2·3)은 반드시 제목·이유로 시작.** 주제 없이 "1, 2, 3"만 = 이탈. 항목이 길면 블로그로 감 — 과감히 자르기.
- ★ 생성 결과가 길면 사후에 자르지 말고 **처음부터 짧은 버전을 요청**.
- 스토리텔링 훅 OK, 단 문장은 더 짧게.

## ★ 승자 표현
- "일본에서도 없어서 못 사는 추천템" / "일본에서도 수량 제한 있을 정도로 유명하다"(해외 희소성 = 사회적 증거)
- "한 번쯤 고민했을 OO, 착색 없이 해결"(고통+해결)
- "감다살이라고 난리 났다" / "OO 사고쳤다"
- "이거 예쁘다고 생각한 적이 없었다. 근데 어디든 착붙더라"(기대 vs 현실 반전)
- "출시되자마자 완판됐다더라" / "역대급 디자인" / "무드가 미쳤다" / "신는 순간 레전드"
- "양말계의 에르메스"(카테고리 + 명품 비유)
- "OO에서 20, 30켤레 쟁이는 이유를 알겠다"(유명인 쟁임 증거)
- 커버 키워드: 미쳤다 / 에르메스 / 효자템 / 꼭 사와야 하는 / 1위 / 감다살 / 아디다스 신상
- ★ 증거 앵글: **무인양품·돈키호테 → "중국인들이 다 쓸어간다더라"**, 화장품은 **친구·전문가**.
- ★ 약한 스토리 훅 수정: "코스 들고 갔는데 카트에 똑같은 게 있더라" → "**이게 요즘 난리더라…**" / "**와 니네 이거 알아?**" — 약간 과장해서 "다들 난리"로.
- 레시피: "레스토랑 가지 말고 **집에서** 이거 만들어봐" — 이미지에 레스토랑급 비교가 보일 때만 성립.

## ⛔ 패자
- **느낌표(!) 많은 훅 = 별로, 저조.**
- 비교 대상이 이미지에 없는 "레스토랑 가지 말고".
- **미괄식**(긴 도입, 약한 임팩트 "카트에 쟁이더라").
- 제목·주제 없는 번호 나열, 항목 긴 나열.

## ⛔ 계정 회복 규칙 (신규 수치)
- ★ **계정 전체 조회 붕괴**(예: 팔로워 1,300인데 전부 100 미만) → **3~4일 휴식 후 꾸준히**. 1~2개 글만 죽었으면 쉬지 말고 계속.
- ★ **"너무 낮음" 기준 = 조회 100 이하.** 200이면 "회복될 계정". **조회 0 = 글 자체 문제** → 글 검토.
- ⛔ 죽은 계정에 집착(더 올리기·좋아요)하면 정지. 쉬는 게 낫다.
- ★ 댓글 삭제당함 → 3~4일 휴식 → 며칠 일상글 → **1~2일 더** 기다렸다 수익화. 전력 있으면 1~2일 일상글만, 3일째부터 수익화.
- ★ **다계정 발행**(예: 500+ 계정 4개로 하루 20개): 계정당 5개, **같은 계정 글 간격 30~60분**(500+ 성숙 계정은 10~20분), **계정 전환 시 간격 불필요.** ⚠️ **성숙 계정 한정** 강조. → 우리 규칙(같은 계정 ≥4h, 계정 간 1~4h 랜덤)과 충돌 — 우리는 훨씬 보수적.
- 같은 글을 내 계정 1~4에 교차 게시 OK("저작권은 본인"). ⚠️ 우리 동시발행 금지 규칙과 충돌(시차 두면 양립).
- ⛔ 캐러셀의 **"광고" 표기는 좌상단**(우상단은 페이지 카운터에 가려 신고 성공 가능).
- ⛔ 아마존 링크도 스레드에서 공시 문구 필요(미국=영문, 일본=일문).

## 알고리즘
- 급락은 월 300만 수강생도 겪음 — "파도가 안 왔을 뿐".
- 스하리·일상 ~10뷰인데 수익화 글은 수백 → 아직 알고리즘 파도 못 탐 + 템플릿이 나와 맞는지(주제·품질) 테스트.
- ★ 스하리 뒷삭은 300 이상이면 무시. **하루 -300 같은 대량 감소 = 스레드 스팸계정 정리**(내 탓 아님). 강사: 팔로워 2.1만/팔로잉 4,900.
- 업로드 50%에서 멈추는데 일상글은 됨 = 미디어·캐시·앱 문제(계정 문제 아님).

## 🔜 통합 후보
- **계정 붕괴 판정 수치**: 계정 전체 <100 → 3~4일 휴식 / 200은 회복 중 / 0은 글 문제 → reach-health·블란챗 판정(최근3건<20뷰)과 대조해 기준 재조정.
- **"300 미만도 링크 뺀 수익화 스타일 글 계속"** → 쇼핑 게이팅에 걸린 계정은 일상글로 강등 발행(현재는 아예 안 뽑힘).
- 다계정 간격(성숙 계정 한정 30~60분) → 페이싱 재설계 근거(단 우리 규칙 더 보수적).
- 나열식 제목 필수, 느낌표 과다 금지, 미괄식 금지 → 카피 규칙.
- 해외(일본어/영어) 계정 + 아마존 → 장기 확장 옵션.
