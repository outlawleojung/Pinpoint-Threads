# 강의 전술 — 3분 스레드 정규강의 1강

> 강사 본인 경험 기반 "평균지"(공식 규칙 아님). ⛔=하드룰, ★=강한 권장. 타임스탬프는 6시간 원문 근사치.
> 출처: 라이브 강의 녹화본(Vimeo 임베드) 오디오 전사. 원문 전사: 로컬 `Downloads/threads_lecture_1.transcript.txt`.

## 1. 계정 안전·정지 회피
- [00:00:12] ⛔ 신생 계정이 팔로우·좋아요·게시글 과다 → 스팸검열 정지 (강사도 5~6개 날림).
- [00:01:57] ⛔ 초반엔 본인 글에 좋아요 누르지 마라.
- [00:15:32] ★ 구글 OTP 2차 인증 필수 — "사람 같은 계정"으로 인식돼 정지 시 생존.
- [00:18:51] ⛔ 인스타 계정센터 "동의"=계정 통합 → 반드시 "아니요"(연쇄 정지 방지).
- [01:19:15] ⛔ 정지된 계정·같은 이메일 계정도 삭제·폐기 금지 ("삭제(외부 이동)"로만 분리).
- [01:37:51] ⛔ 좋아요·댓글·리포·팔로우를 짧은 시간 몰아서 = 정지 트리거.
- [01:38:17] ⛔ 같은 글 3개+ 계정 같은 시간대 동시 발행 금지(신규). 전 계정 800~1000+면 가능.
- [02:02:03] ⛔ AI 이미지·영상엔 "AI 레이블" 필수(한 장이라도). 텍스트 생성글은 불필요.
- [05:47:02] ⛔ 비속어·선정적·정치 금지.
- [05:51:42] ★ 신규 계정은 이틀 정도 글 없이 두고 2차 인증만 먼저.
- [05:59:22] ★ "2시간 텀" = 글·댓글·마팔 등을 한 번에 몰지 말고 텀 두기.
- [05:36:22] ⛔ 알람 맞춰 칼같이 X + 밀린 것 몰아올리기 X. 아침/점심/저녁/자기전 느슨하게(번아웃 방지).

## 2. 계정 생성·워밍업 카데스
- [00:02:13] ★ 계정 생성 3일 간격.
- [00:03:24] ★ 지메일 1개당 스레드 2개까지(3번째부터 새 지메일).
- [00:18:01] ⛔ 하루 인스타 1개만 생성.
- [00:16:30] 스레드=인스타 필수(인스타 가입 후 스레드 로그인). [05:39:21] ⛔ 인스타 1개당 스레드 1개.
- [00:42:09] 인증 셀카 필요(본인 얼굴, 10계정도 같은 얼굴 OK).
- [00:45:16] ★ 새 아이디마다 2차인증·인증셀카·프로필 3종 빠짐없이.
- [01:19:27] ★ 모든 작업 폰으로(PC는 계정 전환 불가).
- [01:23:01] 꾸준히 하면 팔로워 주당 ~100명 증가.

## 3. 발행 볼륨·타이밍 (팔로워 구간표 — 핵심)
- [01:05:45] ⛔ 0~100명: 보수적. 하루 1~2개, 2개면 2시간+ 간격, 마팔 1~2/일, 좋아요·댓글 참기.
- [01:08:47] 100~300명: 하루 3~5개.
- [01:08:57] 300~500명: 하루 3~10개, 1시간 2개 이하. ★ **수익화글은 팔로워 300+부터 시작.**
- [01:09:59] 1000+명: 웬만하면 자유.
- [03:21:23] (숙련) 수익화글 하루 10~15개(강사 12개). 개당 7분(초보 12~15), 복붙 1분.
- [05:14:26] 300+면 일상+수익화 각각 하루 대여섯 개. ★ 수치 집착 X, 루즈하게.
- [01:15:52] ⛔ 스레드 네이티브 예약 발행 안 씀(버그로 동시발행 위험).
- [00:29:11] ⛔ 계정 비공개 전환 금지(수익화 위해 공개 유지).

## 4. 재사용(재탕) 알고리즘 — ★핵심 수익 레버
- [02:21:58] ★ 조회수 1000+ 글은 **원문 그대로 복붙 재발행**(레퍼런스 아님). 계정 문제 없음. 횟수 무제한.
- 재발행 빈도:
  - 스하리글: 조회수 1000+면 하루 1번+ ([02:26:07])
  - 일상글/스토리형: 7일에 1번 ([02:26:15])
  - 틱톡라이트류: 하루 1번 ([02:26:45])
  - **쿠팡 파트너스: 3일에 1번** ([02:27:40])
- [02:31:00] ★ 절대치 아니라 **비율(좋아요/조회, 댓글/조회)** 로 재탕 가치 판단. 비율 높으면 조회수 낮아도(타이밍 문제) 재탕. 조회수 압도적이면 비율 무시.
- [02:38:57] 평균은 게시글 ~10개부터 산출. 비율 좋은 글 = 아카이브해 "무기".
- [02:19:24] ★ 휘발성 3~5일: 글은 3~5일만 조회 나옴 → 계속 새 글 + 재탕.

## 5. 스하리·팔로워 (인식 재정립)
- [01:22:16] ★ **팔로워는 수익화와 직접 무관.** 모으는 이유 = (1)계정 안전 (2)스하리 이벤트 타이밍.
- [02:08:31] "천명프로젝트" = 루머에서 나온 품앗이 문화(실제 조회수 수익화 안 됨).
- [02:10:41] ⛔ 스하리 하러 남 계정 돌며 손품 X (정지 위험) → 스하리 글 써서 상대가 오게(그물낚시).
- [02:12:27] ★ **"뒷상"(안 갚음) 신경 쓰지 마라 — 계정 지키기가 1번.** 반하리 안 해줘도 알고리즘 안 망가짐([05:26:37]).
- [01:44:17] 리포스트 = 내 팔로워에게 노출(확성기).

## 6. 콘텐츠·카피·후킹 (7공식)
- [03:25:03] ★ **버티컬 알고리즘**: 계정 아니라 게시글마다 알고리즘 → 아무 주제나 섞어도 계정 안 상함, 관심자에게 노출. 계정별 컨셉·톤 통일 불필요.
- [03:28:29] ★ 초보는 다양하게 많이 써서 데이터(평균) 쌓기.
- **7공식:**
  1. [03:34:50] 가독성: 2줄 안 띄워도 됨 · 3줄+ 줄 띄우기 · 4줄+ 2줄+2줄 분리. 첫 줄 짧게. 긴 줄은 중간에 끊기.
  2. [03:39:51] 리듬감: 다 띄우지 말고 붙일 건 붙여 강약.
  3. [03:42:21] ★ 두괄식: 결론·킬포인트를 첫 줄에(썸네일 역할).
  4. [03:46:50] ★ 질문 던지기(마지막 줄) → 댓글 유도. ⛔ 게시글당 질문 1개만([04:32:00]).
  5. [03:52:38] 나열식(넘버링): 끝까지 보게+캡처·공유 유도.
  6. [03:54:24] 공감성(성공보다 실패 스토리) — 스레드=공감의 장. (수익화엔 큰 도움 X)
  7. [03:56:18] 정보성: **공유수가 최강 지표**(외부 유입). "필수템/저장하세요"류.
- [03:47:52] ★ **밸런스게임(A vs B)** 이 댓글 최강 유도. ⛔ 선택지 2개만([04:14:38]).
- [05:28:26] ⛔ 이모지·사진·영상·GIF·설문·스포일러는 조회수에 영향 X — "사람들이 좋아할 콘텐츠"만이 핵심.
- [02:29:32] ⛔ 남 글 그대로 복붙 금지(도용) — 벤치마킹만. 내 글은 복붙 OK.

## 7. 쿠팡 파트너스 수익화
- [05:57:26] 쿠팡 파트너스 개인1+사업자1=2개. [05:57:41] 스레드 여러 개여도 파트너스 1개에 연결.
- [06:01:51] ⛔ 자가구매 시 동일 IP면 수수료 취소 → 가족(배우자) 링크로.
- [02:14:37] ★ 수익화글은 **댓글에 쿠팡 링크**. 광고 티로 이탈해도 삭제 X(그물낚시). 링크 빠뜨리면 "링크 왜 없냐" 댓글 달림.
- [01:53:59] ★ 본문 작성 시 "스레드에 추가"로 **댓글 동시 작성 → 무조건 상단 고정**(고정 버튼 안 눌러도). 본문+동시댓글=하나의 게시글로 판단, 초반에도 안전.
- [05:55:10] ★ 링크 걸어도 조회수·도달 안 떨어짐.
- 목표: 조회수 1000+ 글 아카이브 → 복붙만으로 하루 20~30만원(강사 ~170개 확보).

## 8. 알고리즘·도달·노출
- [05:33:32] 조회수 상승 트리거: 게시글 클릭·좋아요·댓글 클릭·댓글·리포·공유. (2차 KPI "댓글 조회수"=댓글 클릭 시↑, 수익화 링크 노출 지표)
- [01:49:11] 주제추가(topic tag)·해시태그 = 조회수·상위노출 영향 없음, 1개만 가능 → [05:25:30] ⛔ (일반글엔) 시간낭비, 하지 마라. ※ 단 스하리는 태그가 발견 경로라 예외.
- [04:52:51] ★ 알고리즘=파도(제어 불가). 30분/하루 조회 0이어도 정상, 조급 금지. 할 일=꾸준+비율 좋은 글 재탕.
- [04:30:11] 조회 0·삭제 후 0 ≠ 정지.
- [01:41:21] 해외 업로드도 문제없음.

## 9. 프로필·세팅
- [00:48:29] ★ 프로필=실사(본인 얼굴) 베스트. 싫으면 일러스트/지브리풍/반려동물.
- [00:49:03] ⛔ 실사풍 AI 사진 금지("로봇=작업계정"으로 걸림) → 일러스트/애니 스타일.
- [00:53:34] ⛔ 연예인 사진 그대로 금지 → GPT/제미나이로 애니 변환.
- [00:52:22] ★ 프로필 여성 권장(소비력). 남성은 1차는 남자 연예인 기반.
- [00:55:59] ★ 다크보다 밝은 이미지. 얼굴 크게(피드에서 작게 보임).
- [01:01:31] ⛔ 프로필 세팅 안 하면 봇 인식 → 무조건 세팅.
- [01:37:11] 소개글 안 써도 됨(수익화 목적, 퍼스널 브랜딩 아님).

## 10. 기타
- [01:57:41] 임시저장(메모지)을 보관창고로. 복사→"취소"→다시 붙여넣기로 재발행.
- [05:48:10] 아카이브: 노션 추천(따옴표 안 붙음). 시트는 큰따옴표 붙으니 제거. 최후엔 카톡 나와의채팅.
- [04:58:15] 일상글 1순위 목적=계정 안정화(조회·팔로워 아님). 사진·정성 불필요.
- [04:48:08] 일상글 체감: 1천=낮음, 1만=홈런, 10만=대박. 벤치마킹 기준 1만+.
- [03:34:29] ★ "100% 딸깍(완전 자동)은 없다" — 생성글도 휴먼터치(가독성·리듬감) 필수.
