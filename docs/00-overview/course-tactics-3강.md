# 정규강의 3강 — 볼륨 시스템 · 소싱 · 수익화 운영

> 코드 반영은 12개 완료 후 통합 때. 하단 "통합 후보"로 이관.

## ★★★ 전략·운영 (최종 목표 5가지)
1. **글 1개 5분 이내**(원래 기준 2~3분). 주 1회 카테고리별 타이머로 재고 병목 점검. 준비물 5개(쿠팡파트너스 웹·구글앱 렌즈·샤오홍슈·파파고·댓글양식)를 켜두고 오가면 2~3분.
2. **재활용 수익화 글 300개**(전 계정 합산). 자기 전 그날 글 확인 → **수익화 글은 조회 1만+**, 일상·스하리는 1천+ 을 노션/시트에 저장. 근거: 하루 20개×7일=140 → 2주분 무한 반복. 사진·영상도 재사용. 300개 뒤에도 신규 소싱 계속. 새 계정도 팔로워 300 넘으면 이 재고 사용.
3. **하루 최대 게시 30개 역량** = 팔로워 1,000+ 계정 3개. 팔로워별 하루 수익화 글 한도: **300명 1~2개 · 500~1,000명 5~7개 · 1,000+ 7~10개**. 평소 루틴은 10~15개(많으면 20), 30개는 명절·아이폰 출시 같은 대목 포화용.
4. 잘 팔리는 글은 쿠팡 링크를 **네이버 쇼핑커넥트·토스**로 바꿔 수수료 극대화(4주차).
5. 판다랭크·홈쇼핑모아 트렌드 점검은 월 1회.

- ★ **볼륨 퍼널**: 이미지 2장으로 ~3분에 하루 20개 → 다음 주 반응 좋은 10개 추려 비슷한 글 10개 더 → 추리고 추려 "무조건 될 것"만 남김. 동영상 제작은 비추(목적은 "궁금하게만"이지 품질 아님).
- ★ 댓글조회율 높은 글(비비안웨스트우드 시계 9만/1.2만)은 **하루 1회, 좋으면 하루 2회까지 재게시**. 먹힌 소재는 주 5회("퇴근할 때마다" 식). 잘 된 글은 다음 날이나 그다음 날 꼭 다시.
- 시리즈 확장: 한 가수로 성공 → 1·3주 뒤 다른 가수·감독·배우·선수로.
- 조회 500은 비율 10% 넘어도 저장 가치 낮음 — 비교는 조회 1천+ 끼리. 저조한 글은 본문 바꿔 재게시 OK.
- 계정은 매달 1개씩 추가(만든 지 7일 넘었으면 다음 날 또). ⛔ 팔로워 구매 금지. 팔로워 300은 보통 1~2주. 팔로워는 **스하리가 정보글보다 ~100배 쉬움**, 메타 광고는 돈 낭비. 스하리 하루 1회로 안 늘면 계정 좀 된 뒤 2회.
- 강사 수익화 계정 팔로워 2,000~4,000. 월 900만원 시기 브랜드 순위: **지유·러쉬·셀린느·롱샴**, 그다음 코치·찰스앤키스·나이키·아식스 = 매출의 80~90%.
- 트렌드는 반드시 보되 맹신 X(검색량 1위도 안 될 수 있음). 엑셀 정리 말고 잡지 넘기듯 눈에 익히기.
- 자기 글 복기: 최소 주 30분, 가능하면 하루 30분.
- 소싱에 시간 쓰지 마라 — 샤오홍슈 메인 피드 상단에서 바로 고르고 애매한 건 넘김.

## ★★ 상품 소싱·선정
- **명품**: 롱샴 > 셀린느 > 미우미우 > 샤넬·프라다. 명품 글엔 **브랜드명을 넣는다**(명성 트래픽 차용).
- **의류·잡화**: 즉효 = 유니클로·지유·무인양품·돈키호테 / 다음 = 라코스테·아디다스·나이키 / 블루오션 = 모던하우스·자라홈 / 꼼데(봄 상승)·코치.
- **화장품**: 올리브영(최고) / 블루오션 = SK2·설화수·라네즈·조말론 / 현재 잘 됨 = 러쉬·도브·이솝 / 봄 립 = 맥. ★ **도브는 웬만하면 한다**(강사 도브로 ~200만원).
- **식품**: 샤오홍슈에서 "올리브영 식품 / 무인양품 식품 / 돈키호테 식품"으로 검색(무인양품 식품으로 2주 ~80만원 사례).
- **지유 추천 이유**: 한국 미입점 = 희소성. 일본 상품 인기, 대만 돈키호테류도 블루오션.
- ★ **모르는 상품·무명 브랜드가 오히려 블루오션** — "내가 모르는데 상위 노출" = 좋은 신호. 레드오션만 고르지 마라. **스레드가 유행을 만든다**(코치·롱샴 스레드발 대유행, 무인양품 발뒤꿈치 로션 ~50번 노출 뒤 일본 매장 5곳 품절).
- 키워드 31개 × 브랜드당 5개 = 185글. "검색할 게 없다"는 없다.
- **샤오홍슈 사용법**: 검색 상위 콘텐츠 고르기, 콜라주·분할 이미지 피하기, 다운로드(워터마크) 말고 캡처, **이미지 길게 눌러 이미지검색** → 같은 상품 다른 이미지·영상 섞어 내 콘텐츠로. 동영상만 = 검색 후 "모두→게시물 유형→동영상".
- **상품 식별 = 구글 렌즈**: 샤오홍슈 전체 화면(중국어 설명 포함) 캡처 넣으면 정확도↑, 검색어에 "쿠팡" 추가하면 쿠팡 링크까지. 화장품·식품은 겉포장 사진. 패션 인물은 얼굴 잘라 캡처. 영상 속 인물은 한국인만 아니면 OK.
- ⛔ 미디어 최소 **2개 이상**(영상1+이미지1 또는 이미지2+). 동영상 권장이나 없으면 이미지 2~3개로 충분 — 이미지만으로도 수익 남.
- **연예인 소싱**: 샤오홍슈 카테고리 "스타"(제니·장원영·카리나 3번 검색 후 새로고침) / 구글 "연예인명 + 사복/공항패션" + 기간 필터 1주~1개월 → 렌즈로 상품 식별 → 원출처 검증. 장점 이슈성·트래픽, 단점 번거롭고 앰버서더 명품이라 쿠팡에 없을 가능성.
- **트렌드 툴**: 판다랭크(셀러→키워드→카테고리, 브랜드명 표시 체크, **월 검색량만**) / 아이템스카우트(작년 같은 달 검색수로 다음 달 예측, 반짝 유행 거름) / 네이버 쇼핑베스트→베스트키워드→인기키워드(연령 "전체"). "해외배송" 상품 = 국내 구하기 어려움 = 좋음.
- 가방류는 겨울·연말연초 강세, 3월 이후 약해질 수 있음. 시즌 상품은 저장했다 재활용(선크림→여름).
- **직찍("클래식이 베스트")**: 저작권 자유·도용 시 신고 권한·트렌드 체감. 한 번은 꼭. 서울 몰(더현대 여의도·용산 아이파크·코엑스·타임스퀘어·잠실 롯데·IFC), 촬영 자유 매장(유니클로·에잇세컨즈·ABC마트·러쉬·자라·무신사 스탠다드), 리빙(무인양품·다이소·올리브영·모던하우스·이케아·자주), 일본(돈키호테·지유·유니클로·일본 다이소·무인양품·편의점 전부). 올리브영 ~20분, 돈키호테 층당 ~20분 — "뭐 찍지" 말고 ㄷ자로 전부. 포장 앞뒷면만 찍은 소시지 글이 크게 터짐. 1~2초 짧은 영상도.
- 유머 영상은 수익 연결 어려워 시간 안 씀. 동물 AI 생성 불필요(샤오홍슈에 많음).

## ★ 콘텐츠·카피
- 정보 30%만, **이미지로 뒷받침 안 되는 문장은 뺀다**.
- 브랜드·매장명 일부러 빼서 "어디 건데?" 유도(조선델리 예) — 단 **명품은 브랜드명 넣음**(구분).
- ★ **생성기 초안 휴먼터치 3가지**: ① 상품 풀네임 줄이기(친구 말투 "롱샴 호보백") ② 줄 간격 바꾸기 ③ 핵심 포인트(구하기 힘들다 등)는 **한 줄 단독 배치**.
- 첫 문장에 시의성(봄), 마무리 "봄 준비 미리". AI가 틀린 브랜드(무인양품→지유) 반드시 수정.
- 직접 30초 안에 쓸 수 있으면 생성기 건너뛰기. 생성기엔 이미지 2~3장 + 상품명 캡처 첨부.
- 생성기 단골 멘트(재미나이 티, "휘뚜루마뚜루", "광명")는 식상 → 바꾼다.
- ★ **질문형 마무리는 일상글엔 좋지만 수익화 글엔 X** — "혼자 묻고 댓글(링크)로 혼자 답하는" 셀프 Q&A 모양이 됨 → 마지막 문장을 바꿔라. ※ 1강·피드백의 "마지막 질문으로 참여유도"와 **충돌 → 통합 때 정리**(일상=질문, 수익화=비질문 마무리로 분리 가능성).
- 남편은 "까기"보다 내가 챙겨주는 존재로.
- 반려동물 글에 링크 걸려면 옷·액세서리 등 상품 얘기로.
- ⛔ 욕설은 새 계정 X(팔로워 적으면 "ㅅ"만 넣어도 날아감). 2~3천+이면 약한 욕 대체로 OK.
- ⛔ 연예인 비하·비하할 판 금지. 뉴스 사진 대체로 OK, 동영상 통째 X.

## ★★ 승자 표현
- "이거 자석인 거 알고 있었어?" → 마무리 "네일샵에서 왜 5만원씩… 겁나 후회된다"(돈 낭비 후회)
- "롱샴 호보백 드디어 구함" + "2년 전부터 핫했는데 구하기 힘들다"(한 줄 단독, 희소성)
- "웬만한 가방 제치고 결국 나갈 때 들게 되는 건 롱샴"
- "셀린느 로고 떡하니 있는데도 과시 느낌은 없네"(한국인 명품 과시 심리 정확히 짚음)
- "여기까지 냅다 지르기 잘한 듯"(뭐길래? 얼마 주고?)
- "쿠팡에서 쟁여가라" → "**중국인들이 쓸어가더라**"(사회적 증거형으로 교체)
- "얘네들은 왜 대용량 안 만드는지" / "호텔 가서 걸어주면 끝난다" / "오 콜라보 했네"(담백)
- "다이어트하는데 … 찾지 말걸…"

## ⛔ 패자 표현
- "왜 안 사? / 너도 빨리 사" — "사주세요"로 읽힘. 우리는 궁금하게 만드는 것.
- 상품 풀네임("롱샴 르 플리아주 시티 호보백") — 친구 말투 아님.
- "은은한 향", "부담 없는 빠삭빠삭 식감" — 홈쇼핑 톤.
- 수익화 글 "써본 사람 있어?"로 끝맺기 — 셀프 Q&A.
- 이미지로 확인 안 되는 뒷문장 — 윗줄까지만.

## ★★ 쿠팡 파트너스 운영
- ⛔ **KPI = 본문조회 대비 댓글조회 10%**. 조회 클수록 비율↓(CTR 원리) → 그땐 **절대 댓글조회**를 본다(10만/5천=5%여도 댓글조회 5천이면 좋은 글). 강아지 다이슨 9,200/550(6%)은 수익 도움 X. 조회 280에 대댓글 34도 10%+면 좋은 글.
- 강아지·아이·유머 = 좋아요↑ 댓글조회율↓ → "계정 활성화용", 수익 기대 X.
- ★ **쿠키 전략 = 그물을 넓게** — 궁금하게만 만들면 되고 그 상품이 팔릴 필요 없음(24h 내 아무거나).
- ★ 정확한 상품이 없거나 중고만 뜨면 **쿠팡 파트너스 "검색결과 링크"**를 댓글에(색상 다른 의류도). 사람들이 알아서 찾음.
- ⛔ 신고 메일 72h 내 소명 안 하면 **1회 만에 영구정지 + 누적 수익 몰수**. 경고: 1회 구두 / 2회 그날 수익 몰수 / 3회 한 달 수익 몰수. **매일 아침 쿠팡 가입 이메일 먼저 확인**.
- ⛔ 쿠팡 링크 미리보기 X 누르지 마라(업로드 실패 사례). 쿠팡 로고 떠도 무관.
- **최종 승인 조건**: ① 등록 스레드 URL과 스크린샷 아이디 일치 ② **누적 판매 금액(매출) 15만원+**. 스크린샷은 본문 맨 처음~댓글 맨 끝(광고표시·공정위·링크 전부). 계정당 1장.
- ⛔ 본인 아이디 결제 → 회수·정지. 가족 명의는 편법(같은 IP·와이파이 X).
- **대목 캘린더**: ★설날·추석 최대 / ★**아이폰 출시 절대 놓치지 마라**(하루 20개 중 ~4개 아이폰·케이스) / 3월 아이패드·맥북, 1~2월 갤럭시 / ⛔ 출시 전 미리 X(쿠팡="내일 받기" 수요, 글 수명 3~5일) / 화이트데이·발렌타인 비추 / 5월 가정의 달은 네이버 쇼핑커넥트 / 11월 블프·와우위크, 12월 연말 최고 / 6월 여름 준비(에어컨·선풍기·우산·수영복·제습기·선크림).
- 주간 피크: 일요일 밤·월요일 아침·토요일 낮. 폭우·폭염·폭설 때 더 많이.
- 시간대: 22~24시 / 20~22시 / 07~09시 / 12~13시 (알고리즘은 시간 무관, 확률용).
- **시간대별 아이템**: 아침 색조·다이어트 / 점심 사무·청소 / 오후 간식·가전 / 저녁 식후 장난감·주방·리빙·욕실 / 취침 전 스킨·로션·클렌저 / 주말 장난감·명품 / 목·금 저가 명품(향수·립밤·립스틱·핸드크림) / 평일 사무·주방·욕실. 홈쇼핑모아 편성표로 공부.
- ★ 좋은 소스 보면 요일·시간 기다리지 말고 바로.

## 계정 안전·발행
- ⛔ **일상글 텀 없이 연달아 올리면 밴**(기업이나 계정 잃어도 되는 사람들만 그렇게 함).
- ★ 계정 간 게시 텀(강사): 둘 다 신규 ~2h / 좀 된 계정 ~1h / 오래되고 팔로워 많으면 ~30분. (프로젝트 규칙 "1~4h 랜덤"보다 짧음 — 현행 유지가 더 보수적)
- ⛔ 300 미만 광고글 = 정지 리스크(한 달 뒤 아이디 사라져 있을 가능성). 300 미만은 링크 빼고 일상글처럼.
- ⛔ AI 같은 이미지(배경만 AI여도) AI 레이블 — 없이 올려 ~5일 섀도우밴 경험.
- 게시물 삭제되면 검토요청 후 3~4일 방치. 정지된 스레드는 같은 인스타로 재생성 불가.
- 15분 지나면 수정 잠김 → 문제 있으면 삭제 후 재게시. 삭제 자체는 계정 문제 X.
- 기존 팔로워 ~200 계정도 첫 1주는 0~100단계, 이후 100~300단계처럼.

## 알고리즘
- 긍정 반응자 기반으로 확장, 부정 반응자엔 노출 끊음 → 꾸준할수록 타깃만 남아 쉬워짐.
- **버티컬: 잘 되는 계정이 아니라 잘 되는 콘텐츠.** 계정 운(개복치) 없음.
- 노출 1차 지역, 2차 언어(일본어→일본인). 스하리는 한국에서만.
- "스레드가 쿠팡 링크 글 노출 안 해준다"는 소문 근거 없음(막으려면 아마존·네이버·토스도 다 막아야).
- 워터마크 있어도 조회 잘 나옴, 신고와 무관. 가리기·AI 지우기는 더 이상하고 시간낭비 — 꺼려지면 이미지검색으로 워터마크 없는 버전.

## 🔜 통합 후보 (추적표 이관)
- **재탕 재고 저장 기준**: 수익화 조회 1만+ (저장) vs 우리 위너 기준(1천+ 또는 비율) — 3강은 "재고 300개"용 엄격 기준, 피드백3은 "댓글조회 1천+ 즉시 재사용". 두 층으로 분리 검토.
- **재탕 빈도**: 좋은 글 하루 1~2회 재게시(강사급) vs 우리 텀 쇼핑 3일 — 팔로워 규모별 텀으로.
- **팔로워별 하루 수익화 한도**(300명 1~2 / 500~1,000명 5~7 / 1,000+ 7~10) → 현재 쇼핑 전체 하루 1건 캡 대체 검토.
- **질문형 마무리 충돌**: 일상=질문 OK, 수익화=셀프Q&A 회피 → 카피 규칙 분리.
- 휴먼터치 3가지(풀네임 축약·핵심 한 줄 단독·줄간격) → 카피 규칙.
- "사회적 증거형"("중국인들이 쓸어가더라"), 돈 낭비 후회 마무리.
- **쿠팡 검색결과 링크 폴백**: 정확 상품 없을 때 검색결과 링크 → 매칭 실패 시 대체 경로로 구현 가능.
- 대목 캘린더·시간대별 아이템 → 소재 엔진/발행 타이밍.
- 소재 엔진: 샤오홍슈 이미지검색 + 구글 렌즈 식별 + 브랜드 우선순위 리스트.
