# 용어 사전

프로젝트에서 자주 등장하는 용어의 정확한 정의. 애매한 어휘는 여기 등재하여 문서·코드·대화가 일관되게 하도록 함.

## Threads 관련

### 본문
사용자가 발행하는 메인 게시글 (원 게시글). 이미지·영상 미디어와 텍스트로 구성.

### 댓글
게시글에 달린 첫 번째 레벨 응답.

### 고정 댓글 (또는 "자기 댓글")
**본인이 자기 게시글에 즉시 다는 첫 번째 댓글.** Threads 알고리즘 특성상 이 댓글이 게시글 하단에 상단 고정 효과로 노출됨. 이 프로젝트에서는 **쿠팡 파트너스 딥링크와 공정위 필수 문구를 이 댓글에 배치**하여 본문에는 링크를 넣지 않는다.

- Threads Graph API 관점: 본문을 `POST /me/threads` → `thread_id` 획득 → 그 `thread_id`에 대한 reply를 즉시 `POST` (with `reply_to_id`)

### 대댓글
**댓글에 다시 달린 답글** (2차 nested reply). 이 프로젝트에서 우리가 자동 발행하는 대상은 대댓글이 아니라 **고정 댓글**임에 유의.

## 스하리 관련

### 스하리
**"스**레드 팔로우 + **하**트 + **리**포스트" 3종 세트 상호 액션. 팔로워 부스팅용.

### 맞스하리
내가 상대의 스하리 요청에 응답해서 상호 팔로우·좋아요·리포스트를 해주는 행위. 하루 3~5회 하드 캡 (Meta CIB 감지 회피).

### 스카우트 계정
Threads 알고리즘 학습을 위한 별도 계정. 관심 콘텐츠에 좋아요·저장하여 알고리즘이 유사 콘텐츠를 계속 노출하게 만들어, 그 피드를 소스 풀로 활용. 발행 계정과 IP·페르소나 완전 분리.

## 커머스 관련

### 쿠팡 파트너스
쿠팡의 제휴 마케팅 프로그램. HMAC-SHA256 서명 기반 Open API. 딥링크 생성·상품 검색·통계 제공.

### 딥링크 (Deeplink)
쿠팡 파트너스 대시보드 또는 API를 통해 생성되는 트래킹 URL. 사용자 클릭 시 우리 계정의 수수료가 집계됨.

### 공정위 필수 문구
공정거래위원회 규정에 따른 광고 표시 의무 문구.
> "이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다."

### 무신사 큐레이터
무신사의 제휴 마케팅 프로그램. 이 프로젝트에서는 승인 상태이나 미사용 (§ [A-shopping § 9.2](../01-pipelines/A-shopping.md)).

### 쿠파스
"쿠팡 파트너스"의 인터넷 축약. 사용자 커뮤니티에서 흔히 쓰임.

### 쿠파스 게시글 생성기
사용자가 수동 워크플로우에서 사용하던 ChatGPT Custom GPT. 이미지 1장 기반 짧은 한 문장 카피 생성. 이 프로젝트 Copywriter의 프롬프트 이식 대상.

## Meta 정책 관련

### CIB (Coordinated Inauthentic Behavior)
Meta의 조율된 위장 행위 감지 시스템. 여러 계정이 조직적으로 협업하여 인위적 확산을 만드는 행위를 탐지. 이 프로젝트에서는 계정 격리·타이밍 다변화·콘텐츠 다변화로 회피.

## 시스템 관련

### 파이프라인
소스 수집부터 발행까지의 종단 흐름. 이 프로젝트는 A/B/C 3개 파이프라인 병행.
- **A**: 쇼핑 콘텐츠 (수익화)
- **B**: 스하리 (팔로워 부스팅)
- **C**: 일상글 (엔게이지먼트, 수익화 없음)

### 런타임 모듈
프로덕션 서버에서 실제 실행되는 코드 단위. 이 프로젝트는 12개로 축약. [09-agents/catalog](../09-agents/catalog.md) 참조.

### 개발용 서브에이전트
Claude Code가 이 프로젝트를 만드는 동안만 사용하는 조력자. `.claude/agents/` 정의. 프로덕션 배포물에 존재하지 않음.

### RAG (Retrieval-Augmented Generation)
카피 생성 시 벡터 DB에서 유사한 고반응 게시글 top-K를 검색해 few-shot 예시로 주입하는 기법. 데이터 임계량 도달 후 자동 활성화.

### 페르소나
계정마다 지정된 말투·이모지·활동 시간대 등의 개성. 같은 소스라도 계정마다 다른 문장이 나오게 하는 seed.
