# 마스터반 피드백 2강 — 성과분석 + 승자표현

## ★★★ 핵심 지표·공식 (우리 KPI와 일치 — 강의가 확증)
- **쿠파스 성공 지표 = 댓글조회수 / 본문조회수 ≥ 10%.** (좋아요·공유 아님. 링크 반응률의 대리지표.)
- **수익 추정 공식**: 댓글조회 1만 → 링크클릭 ≈ 1천 → 구매 ≈ 100명 → 건당 200~1,000원 = **글 하나 2만~10만원.**
- 절대 조회수 높으면 10% 미달이어도 OK(예: 6.8만에 3천 댓글조회 ≈ 7~8천원).
- 조회수 10 이하 = 계정 문제(노출차단). 200~300 = 콘텐츠 문제.

## ★★ 카피 정교화 (제일 중요)
- **의도·방법을 노출하지 마라 = 정체 숨기기.** 실패 예: "○○방식이라 이게 된다더라"처럼 방법을 밝힘 → 클릭 유발 실패. 정답은 "왜 그런지 모르겠는데 도움 된다더라"까지만. **궁금하면 클릭하게 두고, 방법을 대댓글로도 알려주지 마라.**
- ★ 단 **최소 키워드는 줘라**: 키워드가 아예 없으면("월세 살면서 나만 이걸 몰랐어?") 홈 도달자는 이미지 봐야 이해 → "나 몰라" 넘김. 홈 도달자는 아직 정보를 적극 찾을 준비가 안 된 상태. → **정체는 숨기되 최소한의 실마리(키워드)는 첫 줄에.**
- ⛔ **스펙·정보 나열 금지**("가성비·혜자·가볍다·용량"). 홈에서 본 1천 명은 "구매 준비 안 된" 상태라 오히려 반감. 스펙은 링크·상세에서 보게.
- ⛔ **지시 톤 금지**("너희도 꼭 써봐야 돼"). → 후기·반응으로.
- **정보 30%만.** 장점 나열 금지 — 주장은 하나. 스토리는 길어도 되나 주장은 하나.
- **두괄식 / 네임밸류는 맨 위 첫 줄에**(둘째 줄 X).
- **"친구랑 대화하듯"** — "올봄/이번 봄" 같은 안 쓰는 말투 X. 불특정 다수보다 특정 인물(옆자리 동료).
- **긁기(포모) 프레임**: "이거 진짜 유명한데 아직도 몰라?", "유행에 뒤쳐진다", "너만 몰랐어", "일본 여행 갔는데 이거 모르면 헛 다녀온 거다". (공정위 문구 있으면 사용 OK)
- **전략 7카테고리**: ①칭찬 ②긁기(포모) ③네임밸류 ④지인활용 ⑤스토리텔링 ⑥문제해결 ⑦후기처럼. (+질문·나열·VS비교·유머·비주얼후킹)
- **비주얼 후킹이 기본값** — 쿠파스는 이미지·영상 확보/캡처가 문구보다 중요.

## ★★ 승자 표현·문구 (원문 인용 — 그대로/변형)
- "우리 집 강아지한테 에어랩 돌려봤는데 성능 지린다"(26만·댓글조회 11.5%)
- ★ "대파값 실화냐?" / "대파 무한리필하는 법 알아냈다" (두괄식 공감→정보, 극찬)
- "딸기바나나 포기했는데 설거지도 거의 없네 미쳤다"
- "간만에 마음에 드는 신발 찾음. 아식스 열일하네. 사고쳤다"(5만)
- ★ 브랜드 "**선 넘었다**" 프레임(재활용): "○○ 선 넘었다", "브랜드들이 왜 이렇게 선 넘어?", "얼룩제거제 선 넘었다"
- "티파니에서 안경을 만들었다 / 티파니 진짜 사기임"(네임밸류)
- ★ "샤넬인 줄 알았더니" → 코치 (변화구, 19만·댓글 3만) / 댓글 "샤넬 8분의1 가격"
- "버터계 에르메스" / "에르메스는 못 사줘도"(키워드 궁금→클릭)
- "남자들은 참 단순해"(39만) / "손주 감기 걸릴까봐 발차기 봉쇄이불"(48만, 문제해결)
- ★ 자기 단점 활용: "매일 화장한다고 지각하는 직원한테 → 이거 쓰니 10분 더 잘 수 있더라"
- "밥솥 끌어안고 먹었다 / 밥 두공기 순삭 / 먹어보면 바로 알거야"(묵은지)
- "중국 가면 이상한 거 사지 말고 이거 사 / 왜 아직 우리나라 안 파는 거야?"(긁기)
- "샤넬은 무조건 이거, 한국인 피부에 찰떡이래"(타깃=한국인)
- "충전선 맨날 바닥에 떨어지던 거, 이거 붙이니 세상 편하다"
- 지인 활용: "인도 셰프님이 알려줬는데 항염 효과", "청담샵 언니가 추천"

## ★ 패자 표현 (금지)
- ⛔ "형광등 켜졌다" / "광명 찾았다" — **재미나이(Gemini)가 남발하는 표현, 강사가 질림.** 삭제 대상.
- ⛔ "올봄 / 이번 봄" — 친구끼리 안 쓰는 말투.
- ⛔ 스펙 나열("가성비·혜자·가볍다"), 지시 톤("써봐야 돼"), 물결(~) 남발, 이모지 남발.
- ⛔ 키워드 없는 글("나만 몰랐어?"만), 모델명만("뉴발 530"·모르는 사람 많음), 어려운 키워드(무지외반증).
- ⛔ 맥락 없는 상품 연결(하수구 얘기하다 대뜸 맥북) — 최소 연관성 필요.
- ⛔ AI 티 문장("지갑이 먼저 결제하려고"는 됐지만 "삐진 거임?" 류는 X).

## 미디어·소싱 (2강 보강)
- ⛔ 동영상 재생바·자막·워터마크 노출 X, 상하좌우 미편집 X("연필 버튼으로 잘라라").
- 음식/식품은 **실사 > AI 이미지**(효율 높음). 캡처는 세로보다 **가로**.
- ⛔ **알고 보니 한국인이 만든 영상 = 사용 금지**(저작권). 중국 소스는 상대적으로 안전(중국인이 스레드 안 함)이나 리스크 0은 아님.
- 직찰 감각: 봉지만 찍지 말고 꺼내/구워/요리 과정까지(비엔나소세지 극찬 사례).
- 아이·반려동물 = 좋아요 많아도 **전환율 낮음** → 기대 낮게(일상글 취급).

## 일반 전술 (2강 보강)
- ⛔ **부정 댓글 삭제·숨김 금지**(체류시간↑·"진짜인가" 다른 댓글 보게·시간낭비). 극단적으로 많을 때만.
- ★ **A/B 테스트**: 케이스1 vs 케이스2를 두 계정/두 주에 각각 올려 비교 → 다음에 반영.
- 재활용: 잘된 글 일주일 뒤 다시. "안다/모른다 A·B계정 분리" 조언은 불필요(다 엉킴) → 그냥 쭉. 목표 **재활용 게시글 300개**.
- 300명 미만/신생은 동시발행 지양(200+면 30~60분 텀). 300+면 막 올림.
- 쿠파스는 **상품 타이밍 중요**(밤=야식, 봄 상품은 봄). 알고리즘 노출 자체는 시간 무관.
- 정산: 쿠팡 익익월 15~20일, 콜렉스 익일 11시. 스레드 댓글조회 ≠ 쿠팡 클릭수(별개).
- 아이디를 처음부터 "○○픽/템"으로 하면 스하리 팔로워 모으기 어려움(광고계정 인식).
