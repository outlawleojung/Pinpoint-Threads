# 정규강의 4강 — 운영 스케일 · 수익 채널 확장

> 코드 반영은 12개 완료 후 통합 때. (p1=본강의, p2=보강·Q&A)

## ★★★ 운영 스케일 (가장 중요)
- **시간 KPI**: 새 수익화 글 **5분 이내** · 재사용 글 **1분 이내** · 일상글·스하리 **10~30초**(일상글은 계정 안정화·"먹히는 글 테스트"용, 공들이지 X). 월 900만~1,300만 강사 전 동업자는 새 글 ~50초, 복붙 ~30초.
- 카테고리별 소요시간 직접 재기. 하루 10개면 **아는 분야 8 : 모르는 분야 2**. 매주 조금씩 단축(30분→27분).
- **재사용 300개**, 저장 기준 **1만뷰+**(현실적으로 5천). 저장 기준값 = 재게시 기대 조회수 → 기준 높을수록 좋음. 하루 1회(늦어도 2~3일)에 지난 글 점검, 1만 넘으면 즉시 저장.
- ⛔★ **재사용 글이 낮게 나와도 버리지 말고 다시 올린다. 재도전 횟수 제한 없음**, 간격만 늘림. **"한 번 떴던 글은 다시 뜬다"** = 강의 관통 원칙.
- ★ **"명예의 전당" 스레드 계정**: 위너만 올리고 다른 활동 X → 정지될 일 없는 외장하드. 링크만 저장하면 원본 계정 정지 시 함께 사라짐. 정지 계정은 데이터 다운로드 불가 → 미리 옮겨라.
- 저장 방식: 카톡 나와의 채팅 Day1~10 + 사진앱 Day 폴더 → 재게시 30초. 도구 무관.
- 시의성 글(BTS 컴백 등)은 재사용 가치 X, 구조만 학습.
- **발행량**: 권장 **하루 10~15개**, 최대 **30개 역량**(피크 시즌 대비). 용량: 300+ 계정 하루 ~2개, 오래된 계정 ~3개(예: 300+ 5개 + 1,000+ 2개 = 30). 최소 하루 3개(하루 1만원 이하), 목표 하루 10개.
- ★ 계정 수보다 질: 팔로워 2천 기준 **2~3계정으로 10~15개**. 강사는 컨디션 나쁜 날 **계정 1개로 10개**(팔로워 많고 오래된 계정).
- ★ **발행량은 한꺼번에 늘리지 않는다**: 10개 문제없으면 11개로 **일주일 유지**, 문제없으면 12개.
- **계정 숙성**: 새 계정 **7일에 1개**(최소 월 1개) 미리. 일상·스하리로 숙성하며 팔로워. 나중 계정은 앞 계정에서 효과 본 **자기 글** 복붙으로 키움(남의 글 X).
- **예비 계정 이유**: 조회 죽은 계정 → 다른 계정으로, 죽은/새 계정엔 검증 위너 올려 트래픽 재생.
- 폰 1대 로그인 유지 10개 한계. 강사 2년 반 16~18개 운영, 그 이상 불필요.
- ⛔ **예약발행 안 씀**(앱 불완전·에러).
- ★ **발행 시각 최적화 신경 X** — 버티컬이라 "올리고 싶을 때가 최적"(참고: 트래픽 피크 22시, 구매력 22·08시·점심). 집착하면 번아웃.
- 링크인바이오(인포크·리틀리) 거치지 X — 쿠팡 직링크.
- 반응 별로인 글도 삭제 X. 계정별 쿠팡 채널ID 분리 비권장(관리 부담).
- 강사 메인 수익 90%+ 쿠팡, 월 900만. 기대수익 쿠팡 > 앱테크 > 뉴스픽.

## ★★ 수익 채널 확장 (링크 교체 전략)
- ⛔★ **기본 링크는 무조건 쿠팡.** 네이버 쇼핑커넥트는 직접구매 수수료 쿠팡의 2배+이나 **쿠키(간접) 수수료 1.4~1.5%로 쿠팡 절반**. 토스는 직접구매만 인정.
- ★ 쿠팡 쿠키 판매 1위는 **생수**, 고수익은 아이폰·맥북·노트북·공기청정기(링크 안 걸어도 팔림). **내가 건 링크 상품 자체가 실제로 많이 팔리는 경우만** 네이버·토스로 교체.
- ⛔ 교체 전 반드시 쿠팡 **상세 실적 리포트**로 "실제 구매된 상품" 확인.
- ★ 교체 방법: 기존 댓글 수정 X → **그 위너를 재게시할 때 댓글 링크를 네이버/토스로 바꿔** 올림.
- ⛔ **링크 2개 동시 X**(쿠팡+네이버 등). 선택지 많으면 "선택 안 하기"를 선택. 링크 1개.
- ⛔ 공정위 문구 필요 = 쿠팡·네이버·토스.
- **테무 어필리에이트**: 수수료 10~30%(쿠팡 ~3%의 3~10배), 블루오션. 단 쿠키 X → **링크 건 그 상품이 팔려야만**. 쓰는 순서: 쿠팡으로 올리고 1주~1개월 뒤 실제 팔린 **Made in China/Vietnam 공산품**만 테무로 교체(명품 부적합). 링크 1개라면 가입 링크 유리.
- ★ **일본어 별도 계정**: 한국인=쿠팡, 일본인=테무/아마존. 한국어 계정에서 일본어 써도 한국인에게 먼저 노출 → 반드시 분리. 일본어 계정도 300+ 후 수익화.
- 세무: 전자상거래 사업자 아니고 연 ~4천만 미만이면 개인(기타소득) 유리.

## 상품 소싱
- ★ **샤오홍슈는 최신순 말고 종합순** — 종합 상위 = 이미 검증.
- ★ **내 취향 투영 X** — 인기순 1위부터 "뇌를 빼고". 내가 안 궁금해도 10만~20만이 궁금해했으면 올려야 함.
- 월 1회 트렌드 점검. 이미지뿐이면 게시물 문구 복사해 재검색+동영상 필터. 자료 없으면 이미지 생성기 보충.
- 직찍은 일본 효율적(돈키호테·GU·유니클로·다이소·무인양품 — "비행기표값 뽑는다"). **오사카** 추천.
- 쿠팡에 없는 품목(주류)은 링크 없는 일상글로. 소스의 사소한 흠(유통기한 등) 무시하고 최대한 많이.

## ★ 콘텐츠·카피
- ★ **제목 변형 3법**(뉴스픽 기법이지만 스레드 공통): ① **1인칭 내 이야기로** ② **스레드 말투로**(기사 톤→질문형) ③ **궁금증 "마법의 단어"** 넣기.
- ★ **계정 페르소나와 화자 일치**: 여성 프로필 계정에 "와이프한테 말실수" X → 계정 자아로 다시 씀. (우리: 계정 personaPrompt·audienceGender와 일치 필요)
- ★ 어휘력 부족하면 **문장 맨 앞/뒤에 감탄사**만 붙여도 확 달라짐.
- ★ **궁금증 3원칙: 궁금하게 · 클릭 유도 · 결말 말하지 않기.** 캡처도 정답 가림. 커뮤니티 캡처는 결말 궁금해지는 지점에서 **2~3줄 가로로**(1줄=맥락X, 4줄+=결말 유추).
- 완벽보다 조금 불완전(정보 30%). 쇼핑 릴스 자막도 의도 숨김.
- 수익화 글이라서 조회 안 나오는 게 아니라 레퍼런스 조사·연습 부족.

## ★★ 승자 표현 (마법의 단어)
- **"의외의 ~ / 의외로 ~"** — 결과 방향을 숨김("12년차 교사 실수령이 의외로 이 정도"). 이 단어 하나로 글 1개 20~30만원.
- **"~했던 비결"** — 연예인 관심층 + 방법 궁금층.
- **"~의 정체"** — "카페에 나타난 키보드의 정체".
- **"~방법"** / **"TOP 3", "~1위"** — 한국인은 순위 좋아함("일본인 수백만 명이 인정한 콜라맛 1위").
- 감탄사 **"덜덜", "미친…"** 앞/뒤.
- **질문형 전환**: "~ 본 사람?", "~ 모여라", "어떻게 복수할 수 있을까?"
- **1인칭 고민형**: "남편이 가난하게 자란 티 좀 내지 말라… 이혼 사유 되려나?" → 댓글 폭발.
- 검색결과 링크 걸 때 명분: **"제품이 품절될 수 있으니 빠르게 확인해 주세요"** / "상품명을 꼭 확인해주세요".
- "댓글에 OO 적어주시면 상품 정보 보내드릴게요" — OO는 **2글자 이하**(댓글 피로도 최소).

## ⛔ 패자 표현
- **결말 공개**("맛있게 검게 익은 바나나 카스테라 레시피") — 클릭 이유 없음.
- **정보 다 주기**("교사 실수령액 375만원") — 반응이 "음 그렇군"뿐, 댓글 없음.
- 뉴스 기사 톤 — "어차피 뉴스네". 자극 없는 제목 — "그래서 어쩌라고".
- 페르소나 불일치. 제목에서 주제 다 밝힌 밸런스게임.

## 쿠팡 운영
- ⛔ 공정위 문구 넣어야 하는 모든 곳, 맨 위 맨 앞("안전 제일").
- ⛔ 쿠팡 상품 URL 그대로 복사 = 수수료 0원 → 파트너스 생성 링크만.
- 쿠팡 상세페이지 이미지 사용 OK. 링크 미리보기는 그대로(지우든 남기든 성과 무관).
- 가품은 판매자 책임(파트너 무관). 스레드 정지돼도 쿠팡 수익은 별개.

## ⛔ 계정 안전 (신규 수치)
- ⛔ **AI 실사 사진·남의 얼굴 프로필 = 영구정지**(불시 인증셀카와 대조). 일러스트·동물 권장. 사람 사진이면 눈·코·입·귀 다 가려진 것만.
- ⛔ **교복 등 미성년자로 보이는 사진 절대 금지** — 해당 전화번호의 모든 계정 생성 즉시 정지. **아기 사진 프로필로 쿠팡 링크 금지.**
- 닉네임·아이디 변경 ~15일에 2회.
- ⛔ 인스타·스레드 **비밀번호 따로** → 통합 시 연쇄 정지.
- ★ **계정 전환 게시 간격**: 새 계정끼리 **1시간**, 300+/오래된 **30분**, 1,000+ 이론상 30분 연속 가능. 와이파이·데이터 무관.
- ⛔ 300 미만 계정 바이럴 글에 **부계정으로 링크 댓글 우회 금지**.
- ★ 글 연속 삭제(스하리 3개 등) → **일주일 일상글만** 후 재개. 조회 10 미만 → **3~4일 휴식** 후 재개, 안 되면 예비 계정. 자동 로그아웃·비번 변경 알림 = 스레드 오류 → 3~4일 휴식.
- 새 유형 글이 바로 삭제되면 그 유형 당분간 중단.
- 연예인 영상 통째·15초+ = 저작권(1~2개월 내 계정 사라짐). ⛔ 비하 판 X. 강사는 연예인 대신 명품.
- 공유 이미지는 다운로드 말고 캡처(중복 업로드 오류).

## 알고리즘
- 두 핵심 = **지역 + 언어**. 해외 생성 계정도 한국어면 한국 노출.
- 스레드는 계정마다 A/B 테스트 중(기능 유무 다름). 3일 된 계정 조회 안 나오는 건 정상. 임시저장 100개까지.

## 🔜 통합 후보
- **"한 번 떴던 글은 다시 뜬다" → 재탕 재도전 무제한**, 낮게 나와도 간격만 늘려 재게시 → repost-planner에 "재탕 성과 낮으면 텀 늘려 재시도" 로직.
- **명예의 전당 = 위너 영구 보존** → 우리 DB가 이미 원본 보존(Post·mediaUrls Cloudinary). 계정 정지돼도 재탕 가능한지 확인(다른 계정으로 타겟).
- **발행량 점진 증가(주 단위 +1)** + 계정 전환 간격(신규 1h / 300+ 30분) → 현재 페이싱(같은 계정 4h, 쇼핑 전체 1/일) 재설계 근거.
- **링크 교체 전략**: 위너 재게시 시 쿠팡→네이버(실판매 확인된 상품만) — repost 시 링크 교체 옵션.
- **페르소나-화자 일치** → 재탕을 다른 계정으로 보낼 때 1인칭 화자(와이프/남편 등) 충돌 검사 필요!
- 마법의 단어(의외로·정체·비결·TOP3), 결말 숨기기, 1인칭 고민형 → 카피 규칙.
- ⛔ 교복·아기·AI실사 프로필 → 계정 세팅 문서.
