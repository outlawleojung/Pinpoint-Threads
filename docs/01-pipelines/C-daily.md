# Pipeline C: 일상글 (엔게이지먼트·알고리즘 활성도 유지)

## 1. 목적

**계정 활성도 유지 (알고리즘 죽지 않게 함)**. 쇼핑 게시글만 계속 올리면 Threads 알고리즘이 계정을 "마케팅 계정"으로 판정하여 노출을 낮춤. 일상글로 콘텐츠 다변화하여 자연스러운 계정처럼 보이게 유지.

## 2. 수익화 없음

Pipeline A와 달리 **링크·상품·수수료 요소 없음**. 순수 콘텐츠 게시.
- 고정 댓글 없음
- 상품 매칭 없음
- 저작권 리스크는 존재 (해외 원본 재사용) but 상업성 요소 없어 A보다 리스크 낮음

## 3. 발행 규모 & 스케줄

| 항목 | 값 |
|---|---|
| 하루 발행 | 계정당 1~2건 (유동) |
| 발행 시간 | Planner가 A·B와 시차 두어 배치 |
| 4계정 합산/일 | 4~8건 |

**Planner 규칙 예시:**
- 아침: 스하리 1건 (B)
- 오전: 쇼핑 1건 (A)
- 낮/오후: 일상글 1건 (C)
- 저녁: 쇼핑 1건 (A)
- (선택) 밤: 일상글 1건 (C) 추가

이렇게 하면 하나의 계정 피드가 A/B/C 골고루 섞여 자연스러움.

## 4. 소스 발견 방식

**Pipeline A(쇼핑)와 다른 방식** (사용자님이 명시). 구체적 방식은 § 미결 참조.

## 5. 콘텐츠 유형 (사용자 실전 사례)

- 재미있는 동물 사진·영상 (강아지·고양이·기타)
- 유머 사진·짤
- 감동/힐링 스토리
- 공감 유도 상황 (실수담, 반전)
- 밈·트렌드 반응

공통 특징: **어그로**를 끌만한 주제 (반응 유도력)

## 6. 발행 흐름

```
1. Source Collector (C 전용)
   → 해외 일상 트렌드 크롤/수집 (구체 방식 미결)
                ↓
2. Media Handler
   → 미디어 2개 이상 필수 (하드 룰, A와 동일)
                ↓
3. Content Classifier (Haiku)
   → 한국 정서 적합성 필터
   → 부적절 콘텐츠 배제 (정치·종교·성인·의약품·규제 품목)
                ↓
4. Cultural Adapter (Sonnet)
   → 자막·설명을 한국식으로 각색
   → 필요 시 오리지널 언어(영/일/중) → 한글 번역
                ↓
5. Copywriter (Sonnet)
   → 어그로형 본문 (짧고 후킹, 반응 유도)
   → 페르소나 톤 반영
                ↓
6. Approval Gate (Telegram)
                ↓
7. Publisher — 본문 + 미디어만 (고정 댓글 없음)
                ↓
8. Performance Collector (24h/72h 후)
   → 반응 회수 → 벤치마크 승격 검토
```

## 7. 계정 페르소나 & 다변화

- 4개 계정 모두 일상글 참여
- 같은 소스라도 계정별 다른 톤·다른 문장
- 계정별 소스 취향 (예: 계정 A는 동물 위주, B는 유머 위주) — 향후 검토

## 8. 하드 룰

- 미디어 2개 이상 필수 (1개면 폐기)
- 부적절 콘텐츠 자동 필터 (Classifier 통과 필수)
- 링크 절대 삽입 금지 (수익화 아님 명확화)
- 스하리·팔로우 유도 문구 금지 (Pipeline B 영역 침범 금지)

## 9. 미결 (Open Questions)

### 9.1. 소스 발견 구체 방식
Pipeline A와 다르다고 하셨는데 구체적으로:
- 인스타그램 팁 계정?
- 유튜브 쇼츠 캡처?
- Reddit / 9GAG / 특정 커뮤니티?
- 페이스북 밈 페이지?
- 개별 브라우징 후 눈에 띄는 것?

→ Pipeline C 상세 브레인스토밍 시 파악

### 9.2. Cultural Adapter의 개입 정도
- 완전 번역까지 (원어가 있으면 한글로 새로)?
- 자막만 추가 (이미지에 텍스트 오버레이)?
- 캡션만 각색 (미디어는 원본 그대로)?

→ 실제 사용자 방식 확인 필요

### 9.3. 저작권 대응
- 원본 크레딧 표기 여부
- 특정 계정 (연예인·기업)은 자동 제외

## 10. 결정 사항 (Decisions)

- 하루 1~2건 유동 (§ 3)
- 주 목적: 알고리즘 활성도 유지 (§ 1)
- 수익화 요소 없음 (§ 2)
- 소스는 Pipeline A와 다른 방식 (§ 4, 상세 미결)
- 미디어 2개 이상 하드 룰 (§ 8)
