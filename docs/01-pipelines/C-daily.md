# Pipeline C — 일상글

_아직 미작성. 브레인스토밍 진행하며 채워짐._

## 예정 섹션
- 해외 일상 콘텐츠 트렌드 수집 (동물·밈·감동 등)
- 한국 정서 적합성 필터
- 문화 각색 (자막·설명 한국식)
- 미디어 2개 이상 하드 룰
- 수익화 없음, 순수 엔게이지먼트
