# Pipeline A: 쇼핑 콘텐츠 (커머스·수익화)

사용자 수동 워크플로우 청취 기반 진행 중. 미확정 항목은 § "미결" 참조.

## 1. 목적

30~40대 주부 오디언스를 대상으로, 해외·국내 트렌드 소비재를 쿠팡 파트너스 링크와 함께 자연스럽게 소개해 수익화한다. 발행되는 게시글은 광고 카피가 아닌 "일상 후기" 톤을 유지하며, 링크는 반드시 고정 댓글에만 배치한다.

## 2. 오디언스 & 타이밍

- **타겟**: 30~40대 주부, **장보기 전** 시간대에 노출되는 것이 최적
- **발행 시간대**: 오전 1건 + 저녁 1건 분산 (계정 내 균일 간격 유지, 계정 간에는 랜덤 시차)
- **하루 발행량**: 계정당 2건 → 4개 계정 합산 8건/일
- **소싱 필요량**: 매칭 실패 여유 감안 12~15건 후보/일

## 3. 소스 발견 전략

세 갈래로 병행:

### 3.1. 샤오홍슈 (小紅書 / RED)
- 패션 잡화 위주
- 반응 좋은 최근 콘텐츠 우선
- 자동화 방식은 미결 (Apify Xiaohongshu Actor vs 자체 Playwright)

### 3.2. Threads 알고리즘 학습형 피드 (스카우트 계정)
- 별도 **스카우트 계정**을 운영하여 쇼핑 관련 콘텐츠에 좋아요·저장
- 알고리즘이 유사 콘텐츠를 계속 노출 → 그 피드가 곧 소스풀
- 스카우트 계정은 발행 계정과 IP·페르소나·팔로우 관계 완전 분리 필수 (CIB)
- 일본·중국·국내 트렌드 모두 이 방식으로 수집 가능

### 3.3. 국내 반응 좋은 게시글
- 번역 불필요, 카피만 각색
- 이미 국내 시장 검증됨

## 4. 소스 → 발행 워크플로우

```
1. Source Collector
   ├─ 샤오홍슈 크롤/API
   ├─ Threads 스카우트 피드 크롤
   └─ 국내 트렌드 크롤
                ↓
2. 미디어 개수 검증 (Media Handler)
   → 미디어 2개 이상만 통과. 1개면 즉시 폐기.
                ↓
3. Content Classifier (Haiku)
   → 소비재 적합성 (suitability)
   → 카테고리
   → 한국어 검색 키워드 추출
                ↓
4. Product Matcher
   → 쿠팡 검색 (동일 우선, 유사 허용)
   → 카테고리가 패션/의류면 무신사 폴백 후보 (현재 미사용)
                ↓
5. Vision Verifier (Sonnet Vision)
   → 원본 이미지 vs 쿠팡 썸네일 정합성
   → 실패 시 Self-Correction Loop: 검색 키워드 수정 후 재매칭 (최대 3회)
   → 3회 모두 실패 시 폐기
                ↓
6. Copywriter (Sonnet)
   → 본문 생성 (18~60자 한 문장, 광고 티 없이)
   → 페르소나 seed 반영
                ↓
7. Reply Composer (결정론)
   → 4가지 양식 중 계정별·요일별 선택 (다변화)
   → 딥링크 삽입 + 공정위 필수 문구
                ↓
8. 미디어 R2 업로드 (Media Handler)
   → 소스에서 다운로드한 이미지·영상을 R2에 업로드
   → Threads 요구 공개 URL 확보
                ↓
9. Approval Gate (Telegram)
   → 프리뷰: 미디어 + 본문 + 고정 댓글 텍스트 + 상품 정보
   → 4버튼: [승인] [본문 재생성] [상품 재검색] [폐기]
                ↓
10. Publisher (승인 시)
    → Step 1: 본문 + 미디어 발행 → threadsPostId 획득
    → Step 2: threadsPostId에 고정 댓글 즉시 등록
    → 링크 자동 프리뷰 이미지 발생 여부 확인 필요 (§ 미결 참조)
                ↓
11. Performance Collector (24h / 72h 후)
    → Threads Insights API로 좋아요·댓글·리포스트 회수
    → 성과 좋은 것 → 벤치마크 승격 (RAG 자기학습)
```

## 5. 미디어 정책

- **하드 룰**: 미디어 2개 이상 필수. 1개면 소스 자체 폐기.
- **출처**: **소스 게시글의 미디어 그대로 사용** (다운로드 → R2 업로드 → Threads 발행)
- **저작권 리스크**: [legal-compliance](../04-safety/legal-compliance.md) 참조
- **크레딧 표기**: 향후 검토 (현재 미적용)

## 6. 고정 댓글 양식 (4종 실전 확보)

`docs/09-agents/pipeline-a/reply-composer.md` 참조. 요약:

| 양식 | [광고] 명시 | 톤 | 공정위 위치 | 링크 반복 |
|---|---|---|---|---|
| 1 | ✅ | 캐주얼 반말 ("완전 급할 땐~") | 하단 | 1회 |
| 2 | ❌ | 정보 안내형 | 상단 | 1회 |
| 3 | ✅ | 캐주얼 감성 ("주말에 이거만") | 하단 | 2회 |
| 4 | ❌ | 상품 소구형 ("안사도 되니까 구경만") | 상단 | 2회 |

**공통 하드 룰**:
- 공정위 필수 문구: *"이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다."*
- 이모지 3~5개 등장 (양식별)
- 상품명 삽입은 양식 4만 (동적 값 필요)

## 7. 상품 매칭 규칙

- **동일 우선**: 소스와 완전히 같은 제품이 쿠팡에 있으면 최우선
- **유사 허용**: 동일 없으면 유사 제품도 사용 가능 (같은 카테고리·같은 형태·같은 용도)
- **유사도 검증**: Vision Verifier가 판정 (score >= 0.65)
- **폴백**: 유사도조차 없으면 폐기 (다음 소스로 이동)
- **채널 라우팅**: 패션/의류/신발/뷰티 → 무신사 폴백 후보 (현재 미사용, 향후 도입 여지)

## 8. 계정 페르소나 & 다변화

- 4개 계정 모두 쇼핑 파이프라인 참여 (파이프라인 특화 없음, 페르소나만 다름)
- 페르소나 실체는 [personas](../06-accounts/personas.md) 미결
- 30~40대 주부 톤이 공통 방향, 세부 톤은 계정별 (예: 아이 있는 워킹맘, 자취 언니, 살림 고수 등)
- **카피 생성 시 accountId를 seed로** 사용하여 같은 소스라도 계정별 문장 다변화

## 9. 미결 (Open Questions)

### 9.1. 자동 링크 프리뷰 이슈
Threads는 URL 텍스트 감지 시 상품 페이지 프리뷰 이미지를 자동 삽입. 수동 시엔 삭제 가능하나 API 발행 시 동작 미확인.
- API 발행에도 프리뷰 생성되는지?
- 파라미터로 disable 가능한지?
- 발행 후 별도 제거 가능한지?

→ `threads-api-expert` 서브에이전트로 검증 예정

### 9.2. 무신사 도입 시점
사용자 수동 워크플로우에서 무신사 사용 이력 없음. 30~40대 주부 타겟과 무신사(20~30대 패션) 오디언스 정합성 낮음.
- 향후 Pipeline C(일상글)나 별도 페르소나 확장 시 재검토
- 현재는 쿠팡만 구현

### 9.3. 소스 자동 수집 방식
샤오홍슈·Threads 스카우트 피드·국내 트렌드 각각의 크롤링 방식.
- [strategy](../05-data-collection/strategy.md) 참조
- Apify vs 자체 Playwright vs 수동 시드 미결

### 9.4. 스카우트 계정 실체화
Threads 알고리즘 학습 피드 활용을 위한 별도 스카우트 계정 운영 방안.
- 계정 개수, IP 격리, 팔로우·좋아요·저장 자동화 정책
- 스카우트 계정도 CIB 감지 대상이 될 위험

## 10. 결정 사항 (Decisions)

- 발행 시간: 오전 1 + 저녁 1 (§ 2)
- 매칭 실패 처리: 유사 없음 폐기, 있으면 Vision 재검증 (§ 7)
- 미디어 출처: 소스 그대로 사용 (§ 5)
- 무신사: 현재 미사용, 쿠팡만 (§ 9.2)
- 계정 역할: 4개 모두 A/B/C 병행, 페르소나만 분리 (§ 8)
