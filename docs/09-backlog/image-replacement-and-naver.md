# 보류 태스크

## 이미지 교체 기능

**배경**: 벤치마크가 직찍 사진 1장이거나, 원본 이미지 재사용이 부적합한 경우 사용자가 직접 대체 이미지 2장 이상을 제공.

**설계 후보**:
- 텔레그램: 스레드 URL 메시지 + 사진 파일 첨부 (grammY의 photo message handler)
- 봇: 첨부 사진 다운로드 → Cloudinary 업로드 → InboundLink 에 `replacementMediaUrls[]` 필드로 저장
- Pipeline A: `replacementMediaUrls` 있으면 그것 우선 사용 (원본 mediaUrls 무시)

**남은 결정**:
- 원본 이미지 무시 vs 백업 보관
- 계정 승인 카드에 원본 vs 대체 이미지 두 개 미리보기 필요 여부

## 네이버쇼핑 링크 지원

**배경**: 좋은 벤치마크의 댓글 링크가 네이버쇼핑 (쿠팡 X). 현재 시스템은 쿠팡 파트너스만 지원.

**현실적 옵션**:
- (a) 네이버 파트너스 프로그램 API 통합 (검증 필요 · 승인 과정)
- (b) 네이버 링크는 커미션 없이 그냥 텍스트 삽입 (트래킹 X)
- (c) 스킵 (쿠팡 상품만 대상 · 네이버 벤치마크는 컨텐츠 참고용으로만)

**권고**: 초기엔 (c) → 데이터 축적 후 (a)
