# 개인정보 처리방침

**서비스명**: Pinpoint Threads
**최종 업데이트**: 2026년 8월 31일
**시행일**: 2026년 8월 31일

---

## 1. 개요

Pinpoint Threads(이하 "본 서비스")는 운영자 본인이 소유·관리하는 Threads 계정에서 콘텐츠 발행·성과 분석·댓글 관리를 자동화하기 위한 개인용 도구입니다. 본 서비스는 일반 대중을 대상으로 한 서비스가 아니며, 운영자 본인의 Threads 계정에서만 동작합니다.

본 문서는 본 서비스가 Meta Threads Graph API를 통해 처리하는 데이터의 범위·목적·보관·삭제 절차를 명시합니다.

---

## 2. 수집·처리하는 정보

### 2.1. 운영자 본인 계정 정보

Meta Threads Graph API를 통해 다음 데이터를 수집·처리합니다.

| 항목 | 목적 | 근거 권한 |
|---|---|---|
| Threads 사용자 ID · 사용자명 · 프로필 정보 | 계정 식별 및 발행 대상 지정 | `threads_basic` |
| 게시글 원문 · 미디어 · 메타데이터 | 발행 이력 관리, 성과 분석 | `threads_content_publish`, `threads_basic` |
| 게시글별 성과 지표 (좋아요·댓글 수·리포스트·조회수) | 콘텐츠 품질 개선 | `threads_manage_insights` |
| 팔로워 총계 · 인사이트 aggregate | 성과 대시보드 | `threads_manage_insights` |

### 2.2. 게시글에 반응한 사용자 정보 (최소한)

운영자 본인 게시글에 댓글을 남긴 사용자의 다음 정보를 처리합니다.

| 항목 | 목적 | 근거 권한 |
|---|---|---|
| 댓글 원문 · 작성 시각 · permalink | 댓글 관리 | `threads_read_replies` |
| 댓글 작성자 사용자명(`username`) | 팔로우백 후보 추천 (수동 실행) | `threads_read_replies` |

**본 서비스는 댓글 작성자의 프로필 상세 정보(이메일·전화번호·팔로워 수 등)를 수집하지 않습니다.** Meta API가 제공하는 `username` 외의 개인정보를 별도로 저장·연결·분석하지 않습니다.

### 2.3. 자동 수집 정보 없음

본 서비스는 웹사이트·앱 형태의 사용자 인터페이스를 일반 공개하지 않으므로, 방문자·이용자에 대한 쿠키·IP·기기 정보를 수집하지 않습니다.

---

## 3. 처리 목적

- 운영자 본인 Threads 계정의 게시글 발행·관리
- 운영자 본인 게시글에 달린 댓글 조회·응대
- 운영자 본인 게시글의 성과 지표 분석 및 콘텐츠 개선
- 팔로우백 후보 사용자명 알림 (실제 팔로우 액션은 운영자가 Threads 앱에서 수동 수행)

**본 서비스는 다음을 하지 않습니다:**
- 다른 사용자 계정 대신 로그인·발행·팔로우 자동화
- 개인정보의 마케팅 활용·제3자 판매·재배포
- 사용자 프로필링, 광고 타깃팅

---

## 4. 데이터 보관 위치 및 제3자 처리

본 서비스가 데이터를 저장·전달하는 제3자 인프라는 다음과 같습니다. 각 제공자의 개인정보 처리방침이 함께 적용됩니다.

| 제3자 | 목적 | 처리 데이터 |
|---|---|---|
| Meta Platforms, Inc. (Threads Graph API) | 원 데이터 소스 | 위 2절 항목 |
| Neon (PostgreSQL 호스팅) | 발행 이력·후보 로그 저장 | 게시글 메타데이터, 댓글 작성자 username |
| Cloudinary | 발행용 미디어 호스팅 | 발행 이미지·영상 |
| Anthropic (Claude API) | 카피 생성용 LLM | 프롬프트 텍스트 (댓글 작성자 개인정보는 전달하지 않음) |
| Telegram | 운영자 승인·알림 UI | 승인 대기 카드 콘텐츠 |

**모든 서버 간 통신은 HTTPS/TLS로 암호화됩니다.**

## 5. 보관 기간

- 게시글 메타데이터·성과 지표: 서비스 운영 기간 동안 보관
- 댓글 작성자 username 및 permalink: 최대 90일 후 자동 파기 (팔로우백 후보 추천 용도 소진)
- 운영자가 계정 삭제 또는 API 접근을 철회하면, 관련 데이터는 30일 이내 파기
