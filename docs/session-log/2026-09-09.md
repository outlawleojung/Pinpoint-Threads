# 2026-09-09 인수인계

## 완료
- 사용자 요청: 분석까지 커밋/푸시 후 원본 보존 흐름 구현, 이어 '마무리는 해야지' 지시.
- 진단 문서 b5a9d9a 푸시 완료. 후속 HEAD 0adc495에서 source-brief.ts가 커밋된 상태 확인 후 그 모듈을 실제 생성 경로에 연결.
- generateCopy가 원본 분석을 먼저 수행하고 동일 분석을 본문 재시도 및 반환 결과에 전달. 복수 후보/계정 프리뷰도 각 배치 내 분석 1회 사용.
- 보존 기준: 사건의 주체/방향·구체적인 관찰·초점·허용되는 표현 변화·미확인 사항. 텍스트/사람의 미디어 설명은 원문에 실제 존재하는 인용인지 검증. 제공하지 않은 이미지 근거 및 범위 밖 포인트 인덱스 거절. 분석 실패 시 한 번 복구 후 중단.
- Line A 초기 생성, 텍스트 재생성, 성과 확산, /copy 테스트의 댓글 생성에 같은 분석과 원문 전달. 댓글도 본문과 함께 원본 보존 검사 후 필요 시 한 번 재생성.
- 쇼핑 원본 보존 검사는 main tier 사용. 실제 테스트에서 fast 검사가 잘못 통과시킨 목격담 사례를 발견해 생략된 주어도 게시자의 체험으로 읽힐 수 있음을 명시하고 main으로 상향.
- RAG에 SHOPPING 유형 필터. 댓글의 근거 없는 '시간 반 줄음', '매일 씀' 등 예시 제거. 재생성 지시는 새 사건/각도보다 원본 유지·한국어 표현 변경 우선.

## 검증
- `npm run test:copy`: 7개 통과. 분석 근거 검증, 입력 부재, 분석 복구 한도, 본문/댓글 재시도 시 분석 공유, 검사 실패 차단, 광고 문구/링크 유지, 후보 간 분석 재사용 확인. 모델 응답을 대체한 오프라인 테스트이며 콘텐츠 품질 증명은 아님.
- `node --import tsx scripts/verify-source-preserving-copy.mts --live --out ...`: 실제 설정된 모델로 텍스트 원문 1건 검증. DB/Telegram/발행 호출 없음.
- 첫 실측: 원작자의 스타벅스 목격 경험을 자기 이야기로 쓴 문구가 생성되고 검사도 통과 → 실패로 판단해 프롬프트 및 검사 강도 수정.
- 수정 후 실측: 본문 '올블랙인데 이렇게 귀여운 건 또 처음 봄', 댓글 '올블랙인데 왜 이렇게 귀엽냐 진짜'. 과거의 자기 목격담 전환 문구는 ok=false 확인. [결과 JSON](../09-backlog/2026-09-09-source-preservation-live.json).
- `git diff --check` 통과. 전체 typecheck는 기존 Playwright 의존성 누락·구형 Prisma Client 문제로 실패. 최종 검사에서 shared/copywriter·source-brief·reply-composer에 대한 오류는 없음.

## 제한 및 다음
- 검증은 원문 텍스트 1건. 실제 영상 이해, 댓글의 부가 가치/반복감, 다양한 소재 품질, 조회/클릭/구매 개선은 별도 확인 필요.
- 원본 분석과 댓글 검사가 추가돼 모델 호출/비용 증가. 이번 최종 실측은 약 15.2초(추가 회귀 검사 호출 포함). 처리시간 일반화 금지.
- 분석은 메모리에서 같은 생성 요청에 공유. DB 영구 저장/프롬프트 버전 추적은 아직 없음. 승인 카드 재생성은 저장된 원문/이미지로 다시 분석한다.
- sourceMediaDescription은 저수준 생성 함수 입력으로 지원하나 텔레그램 설명 입력 및 영구 저장은 미연결. 영상 프레임 추가 추출·영상 누락 차단·상품 동일성 보강은 다음 작업.
- 운영 크론, 실제 발행, DB 마이그레이션은 실행하지 않음.
