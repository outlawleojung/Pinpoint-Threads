# 2026-09-08 세션 인수인계

## 사용자 방향
- 핵심 목표는 기술적 완료율보다 돈이 되는 쇼핑 콘텐츠. 스하리는 팔로워 확보용 독립 활동이며 쇼핑의 전환 단계로 취급하지 않는다.
- 자동 쇼핑 소싱 품질은 부족. 사용자가 제공하는 해외 고반응 쇼핑 콘텐츠를 제대로 해석하고 한국 독자가 반응할 문구로 재구성해야 한다.
- 완결된 설명보다 미디어에 딱 붙는 짧은 구어체·생략·툭 던지는 느낌을 선호.
- 성공 예시는 강사의 쿠파스 게시글 생성기 GPT에서 생성. 사용자가 원본 문구와 미디어 설명을 제공했다. GPT의 작성 방식 설명을 받았으나 내부 지침 원문으로 검증된 자료는 아니다.

## 반영 내용
- src/modules/shared/copywriter/index.ts의 UNIVERSAL_PRINCIPLES 및 Line A 실제 생성 요청 변경.
- 상품명에서 물리적 강점을 뽑아 카피 중심에 놓으라는 지시, 효용/근거 필수, 주어/목적어 명시 강제를 제거.
- 원본의 구체적 포인트 선택 → 한국식 반응 → 미디어와 연결되는지 자가점검. 기본 1~3줄, 문장 수 강제 없음. 페르소나는 원본 내용을 보존하며 어투 조절.
- 미디어가 보여주는 기능 설명 생략 허용. 범용 감탄·반복 마무리·억지 한국 상황·없는 체험/효과/기간 금지. 기존 링크·개인정보 제한 유지.
- 공통 지침은 수동 Line B 큐레이션도 공유. 일상글의 별도 생성 프롬프트와 스하리·네이버 전용 프롬프트는 변경하지 않음.

## 검증 및 한계
- git diff --check 및 TypeScript transpileModule 문법 검사 오류 0.
- 라이브 LLM 생성/발행하지 않음. 변경 지침의 품질 개선은 아직 검증되지 않음.
- 현재 입력은 원문과 이미지 최대 한 장. 이번 작업은 프롬프트 개선이며, 영상 전개 추출이나 별도 평가기를 추가하지 않았음.
