# 2026-09-06 세션 인수인계

## 이 세션의 큰 줄기
사용자 불만("내가 다 개입해야 하고, 개입해도 제대로 안 됨")에서 출발 → 품질/자율성 근본을 잡음. 예측 금지·실측 검증 원칙으로 진행([[feedback_verify_before_done]]). 설계 합의 후엔 게이트 없이 실행([[feedback_execute_dont_gate]]).

## 1. 스하리·트렌드 개선 (오전)
- **스하리 매일 똑같음** → 원인: "몇 달째 아직 N 못 채움" 템플릿 반복 + RAG가 옛 유사글만. 수정: **최근 트렌드 스하리 글 기반**(유사도 아님) + 최근본문 회피 + 금지 정규식(소프트) + **이모지 서로게이트 sanitize**(JSON 깨짐 원인) + 재시도 확장. (`a034cc0`·`c108e0b`)
- **자동 쇼핑 크론 정지** 재확인. **트렌드 다이제스트/서치 = 쇼핑관련(category≠null)만** 필터(인물·뉴스·지명 노이즈 제거). (`2ef8d4e`·`c108e0b`)
- **/published** 텔레그램 명령: 계정별 발행+성과 요약. 오염 상품명("Access Denied") 방어·정리. (`7d02681`)

## 2. 성과 피드백 루프 구축 (핵심) — spec: docs/superpowers/specs/2026-09-06-performance-feedback-loop-design.md
실측 25건으로 뇌피셜(계정별 기준·engagementScore rate) 폐기 후 설계:
- **① scorer** (`a5908b4`): 종류별·풀 기준 winner/neutral/loser. 쇼핑=**댓글조회(클릭게이트)**, 스하리=좋아요+댓글+리포스트. 4/4 실측 통과.
- **② copy-learning** (`e453e78`): winner 구조 요인만 추출(표면 복제 X — 옛템플릿 재학습 방지). 스하리 라이브.
- **③ propagation** (`ea2b6ec`·`d9c3cc1`): 24h·72h 둘 다 winner → 계정별 재생성 카드. 72h 스냅샷 시 자동 트리거.
- **쇼핑 클릭 게이트 = 댓글 조회** (`3fa8eb7`): 쿠팡링크가 고정댓글에 있음 → 본문58 vs 댓글3(실측). replyViews 수집(migration 20260906082301).
- **확산 기준 = 본문조회 ≥ 10,000 절대** (`18e7ee5`, 사용자 결정): "상대 best 재발행 아니라 절대 수치". 현재 최고 3359 → 확산 0 (진짜 히트만).

## 3. 매칭 정확도 T2 (실측 주도)
정답=사용자 입력 상품명 5케이스로 측정:
- **T2-A** (`b1e279f`): 검색어에 **이미지의 색/변형 포함** + 상품종류 이미지 우선 → 5중 4 개선.
- **T2-B** (`29d0fb0`): Vision 검증기 **색·모델 엄격화**(종류만 보고 색 무시하던 것) + 자동 후보 3→6. 실측: 정답 0.93✓, 틀린모델 ≤0.50✗.
- **계정 간 dedup** (`915546f`): 배치 내 다른 계정이 가져간 벤치마크 제외.
- **실측 결론**: 벤치마크 풀 77%가 해외 → 정확 상품이 쿠팡에 없을 때 많음. 합의된 흐름 = **실패 시 사용자께 요청(대기카드)**, 자동 대체·스킵 아님. 매칭 개선은 "쿠팡에 있으면 정확히·없으면 요청".

## 4. 🔑 2라인 쇼핑 전략 확정 (세션 말미 · 사용자 결정)
사용자 슬라이드(쇼핑커넥트 제품선정/판매전략) 기반으로 방향 확정:
- **Line A (콘텐츠 우선)**: 사용자가 던지는 URL 벤치마크 → 상품 매칭 → 콘텐츠. (현행)
- **Line B (상품 우선·신규)**: 트렌드 수집 정보 → **돈 되는 상품 선정**(가격 2~20만·고가 IT/가전·best-seller) → **비교/최저가 앵글** 콘텐츠. 별도 라인.
- **플랫폼: 쿠팡 + 네이버 쇼핑커넥트 병행** (상품별 수수료 높은 쪽).
- **실측**: 쿠팡 검색 API는 **가격·카테고리만** 줌(평점·리뷰·수수료 없음). → Line B v1 = 쿠팡 랭킹 best-seller(수요·후기 프록시) + 가격밴드/카테고리 필터 + 수수료 카테고리표. 평점/리뷰는 Playwright 나중.
- 네이버 쇼핑커넥트 API 통합 = 별도 큰 작업.
