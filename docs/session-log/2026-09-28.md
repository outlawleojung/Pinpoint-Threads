# 2026-09-28 — 텔레그램 네이티브 운영 (발굴 /소재 + X 인제스트)

## 배경
사용자: "언제까지 여기(Claude Code 채팅)에서 URL 올리고 설명하나. 텔레그램으로 모든 것 다 전달·실행되게 만들어." + "제대로 설계해서 만들어봐."

봇 코드 확인 결과 **발행·정정·승인은 이미 텔레그램에서 됨**(URL 붙여넣기, `일상/발행/상품명` 태그, 카드 답장 정정, 승인 버튼). 진짜 빠진 것은 **발굴(discovery)** — 후보 URL을 찾아주는 단계만 Claude 채팅에 남아 있었음.

정서 원칙 갱신: 해외 소스 = 서구(Reddit) X, **정서 가까운 동아시아·동남아**(일본·중국·동남아). Reddit은 정서 안 맞아 반응 안 옴. → 메모리 [project_source_foreign_viral_only] 갱신.

## 한 일 (Phase 1)
1. **X 인제스트**: `InboundPlatform.X`(마이그 `20260928020000_add_x_platform`, Neon 적용) · `platform-detector` x.com/twitter.com/t.co · `adapters/x-adapter.ts`(트위터 syndication `cdn.syndication.twimg.com/tweet-result` — 텍스트·이미지·mp4 variant 한 번에, Playwright 불필요) · registry 등록.
2. **발굴 모듈** `src/modules/shared/discovery/`: `types.ts`·`filters.ts`(정치/슬픔/NSFW 규칙 필터)·`adapters/jp-animal-x.ts`(주력)·`adapters/tiktok-trend.ts`(Apify 액터 게이트, 미설정=degraded)·`index.ts`(어댑터 실행+InboundLink 대조로 재탕 제외+Redis 24h 저장).
3. **봇**: `/소재`(별칭 `/discover`·`/소스`) 명령 + `disc:daily|skip` 콜백 + `sendDiscoveryCard`(썸네일+버튼) + `/start` help 재작성. `src/modules/shared/approval-gate/bot.ts`.
4. **설계 문서**: `docs/08-decisions/2026-09-28-telegram-native-operation.md`.

## 라이브 피드백 반영 (같은 세션 후속)
- **한글 슬래시 명령 안 됨**: 텔레그램은 `/소재`(한글)를 명령으로 인식 못 함(영문만). → 영문 `/discover` 명령 + **한글 텍스트 트리거 "소재"/"소스"/"발굴"**(슬래시 없이, `일상`·`발행`과 동일 방식) 추가. `runDiscovery(ctx,n)` 공용화.
- **동물=영상 필수**: 사용자 "동물은 이미지만으로 부족". buzzweet `/animal-tweet/`는 **사진 위주**라 영상 0건. → 어댑터를 `jp-x-viral`로 재작성: buzzweet **일일 종합글 `/YYYYMMDD-tweet/` 최근 6일치** 크롤 → syndication enrich → **영상(mp4)만** 채택(enrich 상한 55). 검증: 영상 6건(최고 46만 좋아요) 정상.
- **필터 강화**: 범죄·사건사고 누락(칼부림/逮捕/刺 영상 통과) → `filters.ts` NEGATIVE에 체포·기소·강도·逮捕·容疑·刺·襲 등 한/일/영 범죄어 추가. 재검증 시 범죄 영상 제외 확인. (단순 논란/화제는 허용 유지.)
