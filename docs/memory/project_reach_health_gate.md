2026-09-16 실측 도달 진단 (계정 5개):
- **팔로워 수 ≠ 도달.** 팔로워 최다(sookck.kate 364)가 쇼핑 도달 19뷰로 최저. 도달/팔로워 0.0x.
- **일상글(DAILY)이 도달 엔진.** 건강 계정 일상글이 4천~6천뷰(팔로워의 40배)로 터짐. 쇼핑·스하리보다 압도적.
- **계정 두 종류**: (a) 콘텐츠 문제 = 중앙값 낮아도 최근 1만+ 터진 이력(kle0·minyoung·pikkseetem) → 카피로 개선. (b) 계정 억제 = 한 번도 못 터짐, 천장 250~300(sookck·_blanchatt) → 일상글로 워밍업 필요.
- **스하리 팔로워 = 도달 독.** 스하리로 모은 죽은 계정이 초기 반응 0 → 알고리즘이 저품질로 보고 억제. 스하리 강도 재고 필요.

**도달 레버 (2026-09-16 실측):**
- **영상 = 도달 ~9배.** 쇼핑 내에서도 영상포함 1096뷰 vs 이미지only 115뷰(n13 vs n12). 콘텐츠 종류 차이(영상이 이미지보다 도달 높음)일 뿐, "영상 유실"이 아님 — 사용자는 영상 원본은 항상 영상까지 발행함. 실행: **영상 있는 소스를 우선**으로 던지기.
- **발행 시각**: 13~14시 피크(5천~6천), 09·16시 최악(30~180). 표본 작아 참고용이지만 09시 크론 발행은 피크 아님.
- **스하리 볼륨은 도달 원인 아님**(폐기): 전 계정 스하리 14~16건 동일한데 도달은 천차만별 → 스하리 줄이기로 도달 회복 시도 X. 막힌 계정 원인은 콘텐츠/계정레벨(카피 개선으로 검증 중).

**How to apply:** 쇼핑 발행 계정 게이트는 팔로워가 아니라 **피드 도달건강**으로 판정 (`pipeline-a/reach-health.ts` `isShoppingEligible`: DAILY+SHOPPING 최근 도달 중앙값≥150 **또는** 최근 최대≥1000이면 적격 · 이력부족은 팔로워>100 폴백). 억제 계정엔 쇼핑 태우지 말고 일상글로 워밍업. 카피 승리공식은 [[project_shopping_copy_hype_style]] 참고 — 밋밋한 칭찬+소장각 마무리는 도달 저조와 상관됨(회의→반전/장면반응/논쟁질문이 승자).
