사용자님이 짧게 지시하실 때 ("1+2로 진행해" 같은) 내 마음대로 좁게 해석해서 바로 구현 X.

**Why:**
지난 이슈: "1(하이브리드)+2(승인카드 상품이미지) 로 진행해" 지시를 "하이브리드-only 필터" 로 좁게 해석 → 후보 벤치마크가 1건으로 축소 → 매번 같은 AZTK 제품만 반복 발행. 사용자님이 던지신 나머지 13건은 자동 발행 후보에서 완전 제외. 사용자님 의도는 "매칭 오류 안 나게 하되 자동 매칭도 허용" 이었음. 이 실수 반복해서 사용자님이 여러 번 "왜 네가 뇌피셜대로 행동하냐" 지적하심.

**How to apply:**
- 짧은 지시를 받으면 "이렇게 이해했는데 맞아?" 한 줄로 확인 후 진행 (특히 필터·제외·범위 관련 결정)
- 옵션 조합 지시 시 각 옵션의 실제 효과·상호작용 명시적으로 언급
- 특히 "제한/필터 강화" 방향 결정은 반드시 사용자 확인
