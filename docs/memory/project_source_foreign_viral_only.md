**콘텐츠 소스는 "해외에서 바이럴됐지만 한국엔 아직 안 들어온 것"을 가져와 한국에 처음 푸는 것이다.** 쇼핑·일상 둘 다. 단, **"해외" = 서구가 아니라 정서 맞는 동아시아·동남아.**

**Why:** 사용자 지적 2건 —
1. "한국에서 이미 바이럴된 영상을 왜 가져오는 건데?" → 한국서 이미 뜬 건 다 봤으니 신선하지 않고 재탕 티만 남.
2. "래딧은 우리 정서랑 전혀 맞지가 않아서 반응이 오기 힘들다" → **Reddit·서구 밈/유머/정보는 한국 정서에 안 붙어 반응이 안 옴. 후보에서 제외.** 그동안 사용자가 준 소스가 전부 일본·중국·동남아(타갈로그)였던 이유 = 문화적으로 가까워 한국인이 봐도 "귀엽다/신기하다/사고싶다"가 나오는 감성.

**How to apply:**
- **소스 지역 우선순위: 일본(Threads/X/TikTok) · 중국(더우인/샤오홍슈) · 동남아(태국·필리핀·베트남·인니 TikTok).** 서구(Reddit 등) 제외.
- 소재 결: 동물·귀여움·잔잔·기발함(일상), 뷰티·잇템·패션·음식·만족감(쇼핑). "한국인이 봐도 감정 반응 나오는가?"가 필터.
- **한국 Threads 키워드 검색 금지**(이미 한국 유통). 판단 기준: "이게 한국에 이미 퍼졌나?" 퍼진 거면 스킵.
- 발굴 분담(사용자 확정): **둘 다 병행** — 내가 매일 후보를 찾아 목록 제안 + 사용자도 피드에서 본 URL 투입. 내 후보는 반자동(품질 편차 있음), 사용자 URL이 더 확실.
- **실데이터(2026-09-30):** 1천뷰+ 글 10개 전부 해외 **스레드** 원본(샤오홍슈 출처 발행 0). 원본 좋아요는 우리 조회를 예측 못 함(10만 좋아요→0뷰 사례) — 기준으로 쓰지 말 것.
- **해외 OK 범위(사용자 2026-09-30):** 동물·웃긴 **영상**(말 없이 통하는 것)과 쇼핑 상품만. **이슈·화제는 해외와 한국 정서가 안 맞을 수 있음 → 해외 이슈 자동 발굴 X.**
- ⛔ **자동 발굴 정지 (2026-09-30 사용자: "콘텐츠 가져온 것만 봐도 한숨").** buzzweet·스레드 검색 둘 다 품질 실패, 위너는 전부 사용자가 고른 URL. 소재 선정 = 사람. 아침 푸시 크론 제거, 사용자 요청 전 재가동 X. (참고: 과거 구현 `discovery/adapters/threads-search.ts`(비로그인 Relay, 무료). 검색어는 **한 단어만**(띄어쓰기 있으면 0건). 쇼핑도 내가 찾는다(사용자: "쇼핑도 나보고 찾으라는 거네?") → [🛍 쇼핑글] 자동 식별은 브랜드 불일치 사고(무인양품→두발로 양말).)
- 사람이 주는 벤치마크 URL도 대개 이 결. 정치 제외([[project_daily_content_scope]]). [[feedback_korean_source_recreate]]는 재창조 방식.
