**일상글이 터지는 조건 (우리 일상글 20건 실측, 2026-09-30):**
- 소재: 원본 **댓글/좋아요 ≥2%** 영상 → 6건 중 4건 8천~2만뷰. **<1%("보고 끝" 귀여움)** → 8건 중 7건 300뷰 이하. 원본 좋아요 크기는 무관(10만 좋아요→33뷰).
- 카피: 터진 글 = 장면에 대한 짧은 즉각 반응("고양이가 뒷발로 툭 쳐내는 거ㅋㅋ", "역시 남자들이란....ㅋㅋ", "나였으면 소리 질렀을듯"). 망한 글 = 감성·힐링·교훈("하루 피로가 녹음", "곰인형 가질 권리 있지", "다정한 사람일수록…").

**Why:** 사용자 "일상글을 많이 발행해야 해. 공감 가는, 반응이 있을 만한 내용으로". 공감 = 독자가 "나도/우리 애도/나였으면" 자기 경험을 꺼내게 하는 것이지 따뜻한 말이 아님.

**How to apply:** 발굴 `threads-search.ts` DAILY_MIN_REPLY_RATIO=0.015 + 댓글 수 랭킹. 카피 `copywriter/index.ts` dailyToneRules "우리 실측" 블록. 표본 20건 = 가설 단계([[feedback_sample_size_rigor]]) → 발행 늘면 재검증. 아침 08:00 발굴 카드 자동 푸시. [[project_publish_pacing]] [[project_source_foreign_viral_only]]
