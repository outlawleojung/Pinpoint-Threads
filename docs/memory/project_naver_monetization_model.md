네이버 블로그(Pipeline D)의 수익 **핵심축은 브랜드커넥트/쇼핑커넥트 제휴(affiliate)**. **네이버 애드포스트(광고수익)는 2026-09-09부터 "병행"**으로 방침 변경 — "넣을 수 있으면 넣어라". 구글 애드센스는 여전히 아님.

**Why:** 2026-09-07엔 "애드센스 아니라 브랜드커넥트"라며 애드포스트도 제외했으나, 2026-09-09 유튜브 수익 사다리(애드포스트→제휴→광고협업→지식상품→자체상품) 검토 후 사용자가 "애드포스트도 병행"으로 선회. 단 애드포스트는 **신청 요건(블로그 개설 90일+ / 글·방문자 심사)** 때문에 신규 블로그(깜냥로그)는 즉시 불가 → 활동 쌓인 뒤 신청. 승인되면 네이버가 광고 자동 삽입, 코드/글 변경 불필요, 쇼핑커넥트와 병행 가능.

**How to apply:** 콘텐츠·기능은 여전히 제휴 전환 최적화 우선 — 제휴글 CTA, 일상글 소프트 링크([[project_shopping_propagation]]), 공정위 문구 필수. 애드포스트는 계정 설정 이슈일 뿐 코드 작업 없음(요건 충족 시 사용자가 신청). 홈피드 훅·트래픽↑은 제휴+애드포스트 양쪽에 유효. 관련 정책 [[feedback_naver_engaging_not_dry]].
