**일상글(DAILY) 소재는 동물·재밌는 영상/사진뿐 아니라, 화제가 된 사건·논란이 된 사건도 포함한다 (2026-09-28 사용자 확장).** 논란·화제는 오히려 댓글·의견·반박을 부르는 도달 엔진([[feedback_controversy_drives_engagement]]). 일상은 도달 엔진이므로([[project_reach_health_gate]]) 이런 화제성 소재가 잘 맞음.

**How to apply:**
- **정치는 제외** (사용자 명시).
- **★논란·화제는 강하게 편들지 말고 "중립인 척 애매하게" 던진다 (2026-09-28):** "이게 맞다/틀리다" 단정 X. 대신 "이게 맞나 싶다가도 또 그럴 수도 있겠다 싶고", "보는 사람마다 다르겠더라", "뭐가 맞는 건지 은근 갈리던데", 사실만 툭 + "글쎄…/음…"으로 흐리기. 이유: (1) 양쪽이 다 댓글로 싸워서 engagement↑ (2) 한쪽 편들다 계정 욕먹거나 명예훼손 리스크 회피. **쇼핑=당당한 단정(사고싶게), 논란·화제=애매한 중립(양쪽 갈리게+안전)** — 소재 성격 따라 톤이 다름.
- **특정 문구 남발 금지(다양화):** "실화냐?", "말이 되나?", "미쳤다" 같은 어이없음 표현을 시그니처처럼 반복하지 마라 — 남발하면 그것도 정형틀이라 티 난다. 같은 감정도 매번 다른 결로: "~하는 게 가능한 일이냐", "~는 좀 반칙 아니냐", "~보고 헛웃음 나옴", "~ 이거 뭐 하자는 거지", 담백하게 "~하더라"로 끝내기 등. (스하리 [[project_sharing_diversity]] 다양화 원리를 카피 전반에 적용)
- **대놓고 묻지 마라(하수·광고티):** "이거 봤어?/어떻게 생각해?/너넨 어때?" 같은 직접 질문·의견요청 금지. 대신 **사실이나 내 의견을 툭 던진다** — 전언체("~했더라"), 어이없음·반문("~가 말이 되나?", "~ 실화냐?"), 단정("~는 좀 아니지"). 댓글은 그 도발적·공감되는 **문장 자체**에서 나온다(질문으로 구걸 X). 아식스 709·VT "당당한 단정" 원리와 동일([[project_performance_kpi]] 정체숨김, [[feedback_no_promo_tell_in_reply]] 홍보티 금지와 같은 결).
- 주의선: 사실 왜곡·가짜뉴스 X(실제 사건이면 팩트 안에서), 실존 인물·기업 명예훼손·부정 단정 조심([[feedback_verify_brand_facts_in_copy]]), 종교·젠더 극단 논쟁 등 계정 위험 소재 회피, 영상/사진 내용을 말로 중계 금지([[feedback_image_understand_not_describe]]).
- 커머스 없음(일상글). 사용자가 이슈 URL 주면 이 방식으로 재창조.
