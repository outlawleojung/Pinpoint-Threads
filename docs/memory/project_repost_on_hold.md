**재탕은 보류 (사용자 2026-09-30).** 일상 위너 6건 재탕 카드 만들었다가 전부 리젝.

**Why:** 사용자 "발행한 콘텐츠가 많을 때나 재탕이 의미있지. 몇 개 되지도 않는데 재탕하면 티도 많이 난다." 강의의 재탕도 재고 300개(하루 20×7일 순환) 전제 — 우리는 위너 몇 개뿐이라 팔로워가 바로 알아챔.

**How to apply:** 재탕 후보를 먼저 들이밀지 말 것(아침 푸시 등 X). 발행량을 늘리는 게 먼저. 재고가 충분히 쌓이면(계정별 발행 글 다수) 다시 제안. 다른 계정 이관(4강 "앞 계정 자기 글로 새 계정 키우기")은 사용자 확인 전 금지. [[project_course_strategy]]
