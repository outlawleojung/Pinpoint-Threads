쇼핑/일상 카피에서 **이미지·미디어는 "제품을 정확히 이해하고 오류(예: 헌터를 레인부츠로 오추정)를 피하는" 용도**다. **이미지에 뭐가 있는지 문장으로 서술·나열하지 마라** — "빨간 라벨 박혀있는거", "갈색이랑 베이지 나란히", "두 개 놓으니까", "모닥불 앞에서" 같은 이미지 묘사·지어낸 장면 전부 금지(=쓸데없는 사족).

카피는 **원문의 톤·길이에 맞춰 심플하게.** 원문이 "헌터 시즌 곧, 기대돼🤎" 한 줄 무드면 카피도 "곧 헌터 계절이네 벌써 설렘🤎" 딱 그 정도. 원문처럼 자연스럽고 짧게.

**Why:** 사용자가 반복해서 강조 — "왜 자꾸 쓸데없는 사족을 붙여? 원문처럼 그냥 심플하게. 이미지 내용을 굳이 문장으로 설명하지 말라고." AI가 이미지를 보면 그걸 다 서술하려 하고, 길이를 채우려 장면을 지어냄.

**★영상은 특히 더 (반복 실수 2026-09-21):** 영상 카피에서 **영상 안에 뭐가 있는지 중계·해설하지 마라.** 다리 마사지 영상에 "펜으로 길 그어놓고 발끝부터 위로 밀어올리는데…"처럼 동작·화면을 설명한 게 대표적 사고 — 사용자: "마사지 방법 알려주는 영상인데 굳이 펜이 어쩌고 왜 언급? 너는 왜 매번 영상을 말로 설명하려 하지?!" **시청자는 영상을 본다. 캡션은 영상 해설이 아니라 감정·공감·가치(왜 봐야/저장해야 하나)다.** 방법·동작·화면요소(펜·손동작·순서)를 글로 옮기는 순간 사족. "이거 따라 하면"처럼 영상을 **가리키기만** 하고 해설은 X.

**How to apply:** `winning-style.ts` 규칙 — "이미지는 이해·오류방지용, 서술용 아님" + "기본 한두 줄 심플" + "브랜드로 용도 추정 금지". 재생성 스크립트도 **이미지를 반드시 넘기되**(오류방지) 서술은 프롬프트로 억제. 영상=말로 중계 금지, 캡션은 감정/가치. 관련 [[project_shopping_copy_hype_style]] [[feedback_fix_from_source_not_patch]] [[feedback_no_narrow_interpretation]].
