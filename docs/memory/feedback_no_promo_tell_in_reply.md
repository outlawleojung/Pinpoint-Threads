**고정댓글(그리고 본문) 리드에서 "링크를 가리키는" 홍보 티 멘트를 쓰지 마라.** 금지: "좌표 두고 감", "링크 남겨둠", "여기 좌표👇", "문의가 많아서/궁금해하는 스친들 있어서" (아무도 안 물어봤는데 수요 지어내기), "댓글로 남길게".

**Why:** 사용자 반복 지적("좌표를 찍는다느니 이런 멘트 하지 말라고… 왜 자꾸 홍보하는 티를 내냐"). 페르소나가 '판매자 아님·그냥 스친이'인데 링크를 "여기 있음!" 하고 가리키는 순간 광고 티가 나서 몰입·신뢰가 깨진다.

**How to apply:** 멘트를 **없애라는 게 아니다** — [광고] 뒤 리드는 **진짜 사람의 반응/한 줄 감상**으로 (예: "이 향 한 번 맡으면 다른 바디오일 다 밍밍해짐ㅠ", "나 이거 재구매까지 함;;"). 링크는 **그냥 밑에** 두면 됨(가리키지 말 것). 본문은 정체만 숨기고([[feedback_image_understand_not_describe]] 정체숨김 패턴) 자연스럽게 끝, 유도 문구 X. [광고]+공정위는 법적 필수라 유지. 자동 생성 쪽 `winning-style.ts` `REPLY_STRATEGY` connectors("문의가 많아서 링크 남겨둠👇" 등)도 같은 홍보 티라 정리 필요.
