**전략 축(2026-09-29 확정): 수익 = 소재 × 볼륨 × 재탕.** 카피 완성도가 아니라 "터지는 소재 확보 → 두괄식+참여유도 최소 카피 → 발행 → 비율 좋은 위너 아카이브 → 원문 그대로 재탕" 시스템이 승부처. 출처: 3분 스레드 강의 12개(정규4·마스터3·피드백5) 전사·마이닝 — docs/00-overview/course-index.md, course-codification-map.md.

**Why:** 사용자 지적 "이런 내용을 굳이 내가 말해야 알아? 강의까지 제공했는데?" — 강의를 줬으면 방향을 내가 도출해서 끌고 가야 하고, 매번 "어느 쪽으로 갈까요" 되묻지 말 것. 또 "문서화·추적만으론 안 되고 실제 콘텐츠 작성 때 써먹는 게 중요", "카피 생성보다 전체 방향성이 더 중요".

**How to apply:**
- 우선순위: ①재탕 엔진(`repost-planner.ts` · 텔레그램 "재탕") ②소재 엔진(해외 미유입·영상) > 카피 튜닝(이미 충분, 자가검증 게이트 정도만).
- 위너 기준: 72h 조회 1천+ 또는 조회300+ & 비율(쇼핑 댓글조회/조회≥10%, 일상·스하리 좋아요/조회≥8%). 재탕 텀 쇼핑3·일상7·스하리1일. 쇼핑은 CLAUDE.md 14일 동일상품 룰 → 다른 계정으로.
- 버티컬 적용: 성별 애매 상품은 전 계정 허용(명시 성별만 톤 일치). MSG 지인 추천 프레임 허용([[feedback_no_author_circumstance_projection]] 예외 참조).
- 볼륨은 계정 안전 우선 — 무리한 신규 대량 생성 대신 재탕으로 물량 확보. 팔로워 300 미만 수익화 금지.
- 강의와 사용자의 명시적 기존 룰이 충돌할 때만 짚고, 나머지는 강의 기준으로 결정·실행 후 보고. [[feedback_execute_dont_gate]]
