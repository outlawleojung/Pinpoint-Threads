Pipeline B 스하리(맞팔·소통) 글에서는 **계정 페르소나의 개인 정보를 노출하면 안 된다**.

**절대 금지**:
- 자녀·가족 관계 ("애 재워놓고", "우리 애들", "아들이", "엄마라서")
- 구체 직업·근무 형태 ("나이트 근무", "야근", "3교대", "간호조무사")
- 구체 취미·활동 ("홈트 유튜브 보면서", "요가 매트 깔고", "커피 원두 갈다가")
- 거주지·나이 특정 표현
- 콘텐츠 생산·업로드 활동 ("~올림", "~찍음", "브이로그 만들면서")

**허용 (일반 상태만)**:
- 시간 배경: "퇴근하고", "자기 전에", "오늘 하루 끝나고", "이제야 앉음"
- 팔로워 구간 언급: "아직 100명도 안됨", "이제 겨우 300 넘음"
- 소통 요청·뒷삭 X·반하리 약속

**Why**:
- 스하리 대상 계정과 접점이 없는 개인 신상 노출은 오히려 어색·부담
- 4개 자체 계정이 같은 스하리 풀에 노출되므로 특정 신상 드러나면 CIB 위험
- 스하리 글의 목적은 **소통 요청** 자체, 신상 자기소개 X

**How to apply**:
- `sharing-copywriter/index.ts` SYSTEM_PROMPT에 명시
- 페르소나 프롬프트는 어투·톤 판정용으로만 사용, 신상은 절대 본문에 이식하지 말 것
- 다른 페르소나 확장 시(일상글 Pipeline C 등)에도 이 룰을 재검토
