**성과 분석은 이 2가지만 본다 (2026-09-18 사용자 확정):**

1. **1차 = 조회수(views/도달)** — 가장 중요. 글이 알고리즘 분배를 받았는가.
2. **2차 = 고정댓글 조회수 / 게시글 조회수 ≥ 10%** — 딥링크가 있는 고정댓글로 얼마나 유입됐나. 10% 미만이면 본문→댓글 유도 훅이 약한 것.

**좋아요·팔로워는 성과 지표에서 제외.** (좋아요 높아도 조회·댓글유입 낮으면 의미 없음)

**2차 KPI 돌파 패턴 (외부 실측 고반응 · 2026-09-22 winning-style에 코드화):** 댓글을 여는 핵심 = **상품 정체(브랜드·모델명)를 본문에 안 밝히고 "궁금하면 댓글/DM"으로 남기기** → 정체 알려고 댓글 연다. 실측: 아식스 족저근막염 러닝화 글이 모델명 끝까지 안 밝히고 "DM으로 모델명 물어봐서 슬쩍 두고 감" 유도 → 댓글조회 709회. 우리 실패 원인 = 상품 다 특정해줘서(예 "VT PDRN 5천원 60매") 댓글 갈 이유 없앰. 세트: ① 문제·고통 먼저(타겟 공감→조회↑) ② 경쟁템·과거 저격(논쟁→댓글↑). 구조 = 문제→반전→정체는 댓글에.

**데이터:** 둘 다 이미 수집됨 — `performance-collector`가 `threadsPostId`(views)와 `threadsReplyId`(replyViews)를 24h·72h 스냅샷으로 저장. 비율 = `replyViews / views`.

**실측 예(2026-09-17 MUJI):** 조회 1693 · 댓글조회 49 = 2.9% ❌ → 도달은 났지만 링크 유입 실패. 이런 경우 개선점은 본문 끝의 "링크는 댓글" 유도·후킹. 관련: [[project_reach_health_gate]](도달), [[project_reply_link_repeat]](댓글 링크).
