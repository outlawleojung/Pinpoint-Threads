기능 구현 후 반드시 실 데이터·실 호출로 검증한 뒤에만 "완료" 표시.

**Why**: 이전 세션에서 URL 어댑터(Threads/IG/TikTok) 를 OG 파싱 · npm 라이브러리로 만들고 "완료" 표시했으나, 실 URL 테스트 시 전부 안 작동. 40/41 완료 발표가 근본적으로 부정확했음. 사용자가 "단순 예측만 하지 말고, 실제로 검증 단계를 거쳐서 확실하게 매듭짓고 넘어가라" 명시 (2026-09-01).

**How to apply**:
- 외부 API 통합: 실 호출 1회 이상 성공 확인 후만 "됨"
- 어댑터·파서: 실 URL/입력 하나로 e2e 실행, DB 저장 값까지 확인
- 스케줄러·cron: 최소 1회 실 트리거 확인
- 태스크 완료 마킹은 위 검증 통과 후만
- "코드 작성 완료 = 작동" 절대 X
- 확신 없으면 사용자에게 "실측 테스트 하겠음" 알리고 실행
- 실측 못 하면 "미검증 상태" 명시적 표시. "완료" 마킹 금지
