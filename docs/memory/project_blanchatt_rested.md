**_blanchatt_ 계정은 2026-09-17부터 휴식(isActive=false).** 이유: 메타에서 본인인증 재요청이 와서 한동안 접속 불가였고, 그 여파로 도달이 붕괴(스하리 853→1, 일상 296→3 등 전 종류 최근 1~3뷰). 섀도우밴/계정제한 신호라 글을 더 넣어도 워밍업이 안 됨(1뷰 낭비 + 스팸신호 악화).

**2026-09-18 확정 관찰(사용자):** _blanchatt는 **자체 5계정으로 조회한 것 말고 오가닉 도달이 0**. 이전에 본 1~3뷰도 우리가 본 것뿐 → 일상글로도 도달 0이라 워밍업 불가. 회복 대기가 아니라 **메타 제한/하드 섀도우밴 확정**에 가까움. 사실상 **은퇴 계정으로 간주**(파킹, 비용 0). 오가닉 조회가 다시 잡히면(=제한 해제 신호) 그때만 재검토. 5계정 체제 유지하려면 신규 계정 대체 고려(계정 생성은 사용자 몫).

**How to apply:**
- isActive=false라 모든 크론·라우팅이 _blanchatt를 안 뽑음(휴식). 인사이트 수집은 게시글 단위라 계속 돼서 회복 관찰 가능.
- **재가동은 도달 회복이 실측으로 확인된 뒤에만** (isActive=true). 재가동 시 토큰 refresh 확인(휴식 중 refresh 안 됨).
- 코드: `reach-health.ts` `isCollapsedAccount`(최근 발행 3건이 전부 <20뷰면 붕괴) → `isRecoveringAccount`가 붕괴 계정은 제외(워밍업 라우팅서 뺌, 커밋 2719862). 즉 "낮지만 살아있는" 계정([[project_reach_health_gate]]의 sookck)만 일상 워밍업 대상.
- sookck.kate는 억눌렸지만(⛔ 쇼핑) **살아있음**(최근 쇼핑 66~135) → 휴식 아님, 일상·스하리 저강도 유지.
