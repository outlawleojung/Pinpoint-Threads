스하리 글(Pipeline B)이 5계정 매일 **"오래 굴린 계정 + N명 숫자 + 같이 갈 스친 + 뒷삭 없이 반하리 확실"** 한 틀(숫자만 변경)로만 나오던 문제를 근본 개선함. 이 틀 자체가 금지.

**정답 방향 (실측 확정):** 잡담(mood)이 아니라 **실제 고참여 스하리 글의 "에너지 + 매번 다른 각도"**. 수집된 댓글 400~900 글은 텐션·확신이 있음(달리자/1분컷/무한쓰팔🔥/같이 떡상/반하리 자동발사/N명 남았어). "밤에 스레드 켜면 마음 편해지네" 같은 밍밍한 감성글은 반응 X → 금지.

**How to apply (`sharing-copywriter/index.ts`):**
- 훅 = 에너지형 다각도: 마일스톤긴박·하이에너지달리기·같이성장떡상·탑승하이프·초대리액션약속·솔직자조·새싹. 회전.
- **숫자·마일스톤은 `HookDef.milestone:true` 훅에서만** 노출(현재 팔로워). 나머지 훅은 프롬프트에서 숫자 감추고 "N 넘고싶어 금지" → 비마일스톤에 숫자목표(\d명/넘/찍/코앞…) 누출 시 소프트 재시도. **이유: 전 계정이 "N 넘고싶어(숫자만 바뀜)"로 수렴하던 게 사용자 핵심 불만.**
- SYSTEM_PROMPT: 밍밍한 잡담 금지 + 벤치마크 텐션 적극 흡수 + 상투구("뒷삭없이반하리"·"몇달째 아직 못채움") 반복 금지.
- FORBIDDEN_PATTERNS 유지. 신상 노출 금지([[feedback_sharing_no_personal_info]]).

**Why:** 사용자: "매번 똑같이 구걸하듯 같은 멘트" → 잡담으로 갔더니 "전혀 아닌데" → 정답은 수집된 실제 글 에너지 재현. 실측: 7개 중 에너지 다각도 + 숫자는 마일스톤 2개만, 나머지 5개 다른 결 확인. (한때 vibe/kind 방식 시도했다가 밍밍해서 폐기.)

**★ 과잉교정 보정 (2026-09-17):** "에너지 살려라"가 과해져 훅 7개가 **전부 하이에너지 "달리자🔥"로 수렴** + 마지막 줄 **CTA가 매번 "스하리 남기면 (텀없이/바로) 반하리 감/쏨🙌" 동일** → 사용자 "오늘 아침 글도 어제랑 똑같은 패턴". 진짜 문제는 에너지 유무가 아니라 **톤 다양성**. 수정: 훅 풀에 웃긴관찰·손못멈춤자조·담백한초대·마이페이스꾸준·호기심질문 추가(에너지형과 섞음) + "밍밍 금지=무조건 하이에너지"를 "톤 다양성(에너지·웃김·담백·질문 섞고 담백해도 소통콜만 있으면 OK)"로 완화 + **정형 반하리 꼬리표 반복 금지**(담백/질문 톤은 정형구 빼고 소프트 초대로). 검증: 정형 CTA 반복 0/8, 톤 8종 상이. 교훈=[[feedback_dont_reflexively_ban]] 스하리에도 적용(관찰→금지/강제 반사 X, 다양성이 목적).
