네이버 블로그 **일상(정보)글은 반드시 "유용한 정보 주제"에서 출발**해야 한다. 특정 상품/SKU를 글의 주제로 삼으면 안 된다 — 그건 정보글이 아니라 상품 홍보글이 되고, 정보성이 성립하지 않는다.

**Why:** 2026-09-08 사용자 강하게 지적 — 트렌드 상품(쿠팡 SKU "매직캔 매직롤 280 화이트 로고 인쇄 리필")을 일상글 주제로 자동 생성했더니 "이게 정보글이냐, 상품 홍보잖아"라며 반려. 정보글이 상품에서 출발하면 무조건 홍보글이 된다.

**How to apply (역할 분리, 2026-09-08 확정 · 정책 3):** 주제와 상품 신호를 분리한다.
- **주제 선정 = 네이버 자동완성/연관검색어(실제 검색 수요)** (commit 5303187). `src/infra/naver/autocomplete.ts` `buildSearchTermPool(category)`가 고정 니치 카테고리(레트로주방·인테리어소품·생활가전·수납정리)를 씨앗으로 실검색어 풀을 긁고(+1단계 드릴다운), `generateInfoAngle(category, recentTitles, searchTerms)`가 그 실검색어를 근거로 유용한 정보 주제를 만든다. 근본 원칙(사용자, 2026-09-08): **"우리가 글을 쓰는 이유 = 사람들이 좋아하고 보는 글을 써서 트래픽을 얻고, 그 위에 제휴 수익을 얹는 것." 그래서 주제는 "사람들이 실제로 관심있어 검색하는 것"에서 와야 한다.** LLM이 혼자 지어내기(에버그린)나 쿠팡(=뭐가 팔리나, 관심≠구매)은 주제 소스로 부적합 → 폐기. 자동완성 한계: 검색 '여부'는 주나 '검색량(정확한 인기순)'은 없음 → 향후 **네이버 검색광고 키워드도구 API**(RelKwdStat, 월간검색량 제공·무료지만 검색광고 계정+API키 발급 필요)로 업그레이드하면 검색량 기반 선정 가능. 자동완성 결과가 얇은 씨앗(예:"레트로주방")은 폴백으로 여전히 주제 생성됨.
- **쿠팡 상품(NaverTrendKeyword) = 제휴 링크 후보로만.** `pickTrendKeyword`로 골라 `suggestedProduct`에만 넣고, 글에 자연스러우면 `/naverlink`로 붙인다. commit 719b39d에서 `generateInfoAngle`에 trend 키워드 전달 제거.
- 절대 금지: 특정 상품/SKU를 글 주제로 삼는 것(상품홍보글). 좋은 예 "도마 관리법(정보)+도마 링크(선택)" / 나쁜 예 "매직캔 매직롤 리필(상품글)".
- 향후 업그레이드: 진짜 관심 신호가 필요하면 네이버 데이터랩/구글 트렌드(검색 관심) 붙일 수 있음(쿠팡 구매인기 아님). [[project_naver_monetization_model]] — 수익은 자연스러울 때만 얹는 오버레이.
