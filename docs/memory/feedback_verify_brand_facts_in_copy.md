쇼핑 카피의 훅을 브랜드 정체성/카테고리 단정 위에 세우지 마라. **틀리면 훅 전체가 무너진다.**

**Why:** 오니츠카 타이거 메리제인 카피에서 "오니츠카 러닝화 만드는 브랜드 아니었냐" + "발 편한 브랜드가 만든 플랫"으로 훅을 짰는데, 오니츠카 타이거는 **러닝화 브랜드가 아니라** 일본 레트로 스니커즈/헤리티지 브랜드(멕시코66 줄무늬, ASICS의 패션 라인). 사용자: "오니츠카는 러닝화 만드는 브랜드 아닌데." 틀린 전제라 훅이 통째로 폐기됨.

**How to apply:** 색감·디테일·실물감·구매욕처럼 **눈으로 확인 가능한 것**으로 훅을 짜라(이미지 직접 확인 [[feedback_image_understand_not_describe]]). 브랜드 히스토리·카테고리("~로 유명한", "~ 만드는 브랜드")를 꼭 써야 하면 확실할 때만, 애매하면 검증 후. 지명·가격·자격 같은 팩트취약 요소를 피하는 원칙([[project_naver_evergreen_only]])을 쇼핑 브랜드 단정에도 적용. 안전한 표현: "스니커즈로 유명한 오니츠카"(O) / "러닝화 브랜드 오니츠카"(X).
