응답은 항상 한 화면 이내로 짧게. 필요 정보만 요약.

**Why**: 사용자가 명시적으로 "저렇게 길게 늘어놓으면 내가 어떻게 다 읽냐?" 라고 함 (2026-09-01). 긴 응답은 읽지 않고 넘어감.

**How to apply**:
- 옵션 나열 시 최대 3개까지
- 표는 5행 이내로
- Q1/Q2/Q3/Q4 식 다중 질문 X → 가장 중요한 하나만
- 헤딩은 최대 2단계 (#, ##). ### 이하 자제
- 코드 예시는 실제 필요할 때만
- 배경 설명·근거 나열 최소화. 결론 먼저.
- 사용자가 명시적으로 "자세히 설명해줘" 요청 시에만 확장
