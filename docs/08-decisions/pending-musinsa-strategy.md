# Pending: 무신사 큐레이터 활용 전략

**결정 상태**: 논의 완료, 실행 결정 대기 (다음 세션 or 쿠팡 라인 안정화 후)

## 배경

무신사 큐레이터 승인 상태이나 사용자님이 실 활용 이력 없음. 어떻게 활용할지 전략 미결.

2026-08-28 세션에서 정책·구조 상세 확인 완료 → 이 문서에 근거·옵션·다음 결정 필요 사항 기록.

## 확인된 팩트 (공식)

### Attribution 구조
| 유형 | 조건 | 수수료 |
|---|---|---|
| **직접 기여** | 제휴 링크와 **동일 상품** 구매 | **10%** |
| **간접 기여** | 링크 통해 진입 후 다른 상품 구매 | **2%** |

- 쿠팡 24시간 세션 쿠키와 다른 게임
- 무신사는 "정확한 상품 판매 매칭"이 핵심 (10%가 훨씬 큼)
- 간접 기여도 있으니 링크 진입 자체는 여전히 가치 있음

### 링크 2종류

1. **상품 개별 제휴 링크** — 특정 상품 하나 (`musinsa.com/curator/goods/xxxxxx`)
2. **큐레이터샵 링크** — 편집샵 (여러 상품 큐레이션, 프로필용)

큐레이터샵 특성:
- **"프로필 링크 노출만으로 수익 창출 가능"** (공식)
- 한 번 세팅 후 팔로워 유입 시 상시 수익
- 인스타·스레드·유튜브 프로필에 링크 등록

### 광고 표기 (유가광고, 필수)
| 링크 유형 | 필수 문구 |
|---|---|
| 쿠팡 파트너스 | "이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다." |
| 무신사 상품 링크 | "본 링크는 무신사 큐레이터 활동의 일환으로, 링크를 통해 구매 시 일정 수수료를 제공받습니다." |
| 무신사 큐레이터샵 | "큐레이터샵은 무신사 큐레이터 활동의 일환으로, 전시 상품을 통해 구매가 발생할 경우 일정 수수료를 제공받습니다." |

### 부가 혜택
- 당월 정산 대상자에게 무신사 20% 할인 쿠폰 5매 지급

## 오디언스·수익 재정리

| 지표 | 쿠팡 (지금 파이프라인) | 무신사 (미도입) |
|---|---|---|
| 주 오디언스 | 30~40대 주부 | 20~30대 여성 |
| 평균 객단가 | 3만원 | 5~15만원 |
| 커미션율 | 2~4% | 10% (직접) / 2% (간접) |
| 상품당 수익 (평균) | ~900원 | ~8,000원 (직접) |
| 필요 판매 수 (월 30만원) | 333건 | 38건 (직접) |

## 4가지 옵션 (2026-08-28 정리)

### 옵션 A: 별도 20~30대 여성 페르소나 라인
- 5계정 중 1~2개를 무신사 전용 페르소나로 특화
- 소스도 별도 (샤오홍슈 대신 스레드·인스타 20대 여성 감성)
- 무신사 API로 상품 개별 링크 자동 생성 (API 지원 시)
- **장점**: 라인 다각화, 상품당 수익 5~10배
- **단점**: 관리 두 배, 새 페르소나·새 소스 필요

### 옵션 B: 기존 계정 카테고리 라우팅
- 30~40대 주부 페르소나 유지
- 소스가 패션/의류/신발/뷰티 카테고리면 무신사, 나머지는 쿠팡
- **장점**: 코드 무변경 (이미 라우터 구현)
- **단점**: 30~40대 주부가 20대 패션 관심 낮아 반응 저조 예상

### 옵션 C: 큐레이터샵 + 프로필 링크 (자동화 없이 즉시)
- 큐레이터샵 하나 세팅 (30~50개 상품 큐레이션)
- 5개 계정 프로필에 편집샵 링크 등록
- 게시글에는 프로필 안내 문구
- 자동화 파이프라인이 팔로워 늘려주면 편집샵 수익 자연 성장
- **장점**: 코드 변경 0, 오늘 당장 세팅 가능, 지속 수익
- **단점**: 게시글 상품과 편집샵 매칭 없음 (약한 시너지)

### 옵션 D: 완전 보류
- 쿠팡 라인 안정화 (6개월) 후 재검토
- **장점**: 초점 명확
- **단점**: 부가 수익 기회 놓침

## 미확인 결정 근거

- **상품 개별 링크 API 존재 여부**: 공식 가이드는 웹 UI 수동 발급만 안내. API 있는지 확인 필요.
  - **확인 방법**: 무신사 큐레이터 대시보드 도움말 · 개발자 문서 · 지원 문의
  - API 있으면 → 옵션 A 자동화 가능 → 매력↑
  - API 없으면 → 상품 개별 링크는 반자동 (승인 시 사용자 수동 발급 필요)

## 코드 관점

### 지금 그대로 유지되는 것 (변경 없음)
- 커머스 라우터 (`src/infra/commerce/router.ts`)
- Musinsa Adapter stub (`src/infra/commerce/musinsa-client.ts`)
- Vision Verifier / Copywriter / Media Handler

### 도입 시 필요 작업
1. **MusinsaAdapter 실 구현** — API 존재하면 Coupang과 유사 (5~10시간)
2. **Reply Composer 채널·링크 유형별 문구 분기** — 3-way (쿠팡 / 무신사 상품 / 무신사 편집샵)
3. **채널별 페르소나 매핑** — Account에 preferred_channels 필드 추가
4. **Vision 임계값 채널별 조정** — 무신사는 직접 기여 10% 목표이므로 정확 매칭 강화 (0.65 → 0.80)
