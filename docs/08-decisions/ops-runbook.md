# 운영 런북

다른 AI·세션이 이어받을 때 **이 문서대로** 움직이면 된다. 사용자 결정의 근거는 `docs/session-log/2026-10-0*.md`, `2026-10-1*.md`.

## 0. 프로세스 (필수)
- 터미널 3개가 떠 있어야 한다: `pnpm run dev` · `pnpm run dev:bot` · `pnpm run dev:worker` (tsx watch · 저장 즉시 반영).
- **워커가 꺼지면 발행·크론 전부 멈춤** (2026-10-16 오후~10/18 사고). 확인: `npx tsx scripts/ops/queue-status.mts` — 지난 시각인데 APPROVED 로 남은 글이 있으면 워커가 죽은 것.
- 워커를 다시 켜기 **전에** `npx tsx scripts/ops/reschedule-approved.mts` 로 지난 예약을 재배치 (안 하면 밀린 글이 한꺼번에 동시 발행 → 10/1 사고 재현).

## 2. 사용자가 URL 을 직접 줄 때 (채팅 세션)
1. `npx tsx scripts/ops/urls-hold.mts '[["URL","사용자 설명"]]'` → 계정 배정·영상 저장·카드 보류, ①② 후보 출력(HOLD 줄).
2. `bash scripts/ops/frame-grid.sh <영상URL> <이름>` → `.frames/<이름>grid.jpg` 를 **직접 열어 장면 6개 확인** (생성기 상황 설명만 믿지 말 것 — 등밀이를 "회전"으로, 놀이터를 "아빠들"로 오독한 사례).
3. 문구 확정 후 `npx tsx scripts/ops/send-card.mts <postId> '["①","②"]' '<상황 한 줄>'` → 텔레그램 카드.
4. "스하리용" 이면 `npx tsx scripts/ops/keep-sharing-asset.mts <URL...>` → 보관함(`pinpoint-threads/sharing-assets/`)에 영상+정지장면 묶음 저장.
- 사진 1장 글: 파이프라인이 실패(2장 룰) → 웃음 포인트를 Cloudinary `c_crop` 확대샷으로 2장째 만들어 붙임(맥도날드 사례).
- 인용(quoted) 글·텍스트형 글: 미디어 0 이 나올 수 있음 → Relay `fetchThreadsPostRelay` 의 media 로 직접 업로드(확인: `npx tsx scripts/ops/relay-meta.mts <URL>`, 붙이기: `attach-relay-video.mts`). **강제 영상 추출(`hasVideo:true`)은 페이지의 다른 영상을 잡을 수 있으니 반드시 프레임 확인**(하마 사례).
- 로그인 필요 글(민감 콘텐츠)은 Relay 0건 → 넘기거나 사용자에게 파일 요청.

## 3. 문구 원칙 (사용자 확정)
- **일상**: ① 원문 캡션을 한국 말맛으로 옮김(직역 X) · ② 단어 몇 개짜리 반응 한마디("겁나 웃기네ㅋㅋㅋ"). 영상 장면 설명 금지 · 감성·교훈 X · 게시자 본인 신상(우리 남편·우리집) X.
- **스하리**: 반응 상위 실제 스하리를 **벤치마킹**해 담백한 인사 + 반하리 약속(요청 필수) · 반말 위주 · 가벼운 부탁 OK, 하소연·구걸조 X · 한 줄 짧게 · 아침 발행이라 시간·요일·날씨·밤 표현 X · 첨부는 글과 무관한 어그로(같은 출처 묶음만, 다른 영상 섞지 않기).
- 규칙은 **금지로 극단화하지 말 것** (사용자: "하지 말랬다고 완전 제외하지 마, 왜 이렇게 극단적이야").

## 5. 확인된 실패·오해 (반복 금지)
- 버티컬 알고리즘 = 글 단위. "계정별 역할 분담"·"같은 영상 재사용이 붕괴 원인" 같은 계정 단위 가설은 사용자가 반박 → 철회.
- 붕괴 원인으로 데이터가 받쳐주는 것: 링크 글 과다 · 여러 계정 동시 발행.
- 스크립트로 카드 폐기 시 **텔레그램 버튼도 제거**(`bot.api.editMessageReplyMarkup`) — 안 하면 사용자가 눌러 오류.
- 같은 날 같은 계정에서 540과 27이 나옴 → 사용자 "복불복". 결론: 글 하나 다듬기보다 **발행 수(계정당 하루 2) + 위너 재탕**(강의: 소재×볼륨×재탕).
- 국내에서 이미 쓰인 영상(사용자가 "우리나라에서 가져다 썼다"고 알려준 것)은 소스로 쓰지 않는다.
