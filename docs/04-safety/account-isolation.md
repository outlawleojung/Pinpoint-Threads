# 계정 격리 규칙

_아직 미작성. 브레인스토밍 진행하며 채워짐._

## 하드 룰
- 4개 자체 계정끼리 팔로우/스하리/맞팔 절대 금지
- 계정별 페르소나 완전 분리 (accountId를 seed로)
- 계정 간 최소 1~4h 랜덤 발행 시차
- 계정별 활동 시간대 프로필
